# Synthia 平台展示

正式入口：Synthia 页面左下角的 `?`，在当前标签打开 `/presentation/index.html`。

这是一个从上到下滚动的单页，没有计时器或翻页控制。顶部导航可定位到相应段落。

- 痛点后直接展示 CAN 案例，已删除中间的自动开发闭环段落。
- CAN 展示分为“CAN 盲测”（p20）和“CAN 黄金基线”（p19）两个标签，切换保留页面状态。
- 自进化段落内嵌真实技能库与提效页面，数据随平台更新。
- 最后的过程管控段落内嵌 p4 项目，替换静态流程图。
- 嵌入区域可重新载入、展开或独立打开；展开后点击“收起预览”返回。
- 正式站点内同源打开，沿用当前标签页的登录态；嵌入页面隐藏问号入口。
- 本地 HTML 可独立打开，但实时预览需要联网，并可能需要在预览中登录。
- 当前预览为真实可操作网页，请在汇报前准备好需要展示的位置。

## 文件

`index.html` 与正式站点 `web/public/presentation/index.html` 同步。
`讲稿与时间分配.md` 保留四分钟口播参考；页面本身没有计时功能。
`content.json` 为上一版口播内容；预览中的实时数字可能与讲稿快照不同。

原先六页幻灯片预览图片和验证记录不再代表当前版本；当前效果以 HTML 为准。

## 当前版式

按原稿组织讲述锚点：攻关目标与售货机示例 → 三个痛点 → 自动开发与 CAN 对比 → 经验复用 → 工程流程。白底文字提纲，关键词和数据突出；保留三个真实平台预览。自进化数据锚点为 2026-09-29 快照，实时数据以平台为准。
