Synthia UI 的独立 Web 形态是 MVP 交互入口；未来工业软件嵌入形态只复用同一 Core API 和授权边界，不改变权威数据和批准边界。

MCP 与其他 Adapter 也不需要先二选一：Connector Port 语义固定，首个切片实现 MCP Adapter，后续可增加 HTTP/Queue Adapter；MCP 不成为 Synthia Core 或 Connector Worker 的唯一内部架构。
