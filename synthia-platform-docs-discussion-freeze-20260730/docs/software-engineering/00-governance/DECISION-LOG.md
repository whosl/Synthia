| ADR-012 | 2026-07-23 | 提议 | RX 超时在 RX 使能且 FIFO 非空时按位周期计时；成功接收或成功读取重启；FIFO 空/清空、复位或禁用清零；到期置粘滞事件并饱和；W1C 后在仍非空时重新开始完整间隔 | 关闭 RTUART-REV-002 P0-02；批准前不得写入实现基线或作为测试通过依据 |
