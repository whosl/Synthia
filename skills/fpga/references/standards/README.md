# FPGA 标准参考库

本目录保存 Synthia FPGA 工程规则实际引用的标准 PDF、可检索 Markdown 和机器清单。PDF 用于核对页面原意；Markdown 用于搜索和生成，不是批准依据。正式符合性、版本适用性、裁剪和批准仍由授权质量/标准化角色依据受控副本决定。

## 引用闭包

- GJB 9764-2020 直接引用 GB/T 11457、GJB 438B-2009 和 GJB 9432；
- GJB 438B-2009 直接引用 GB/T 11457 和 GJB 2786A-2009；
- GJB 2786A-2009 直接引用 GB/T 11457 和 GJB 438B-2009；
- 已验证的 GJB 9432-2018 正文首页直接引用 GB/T 11457、GJB 5235-2004 和 GJB 9433-2018；
- GJB 9433-2018 直接引用 GB/T 11457 和 GJB 9432-2018；
- GJB 5235-2004 直接引用 GB/T 8566 和 GB/T 11457；GB/T 8566-2022 是当前现行版本，但在项目采用前仍须完成不注日期引用的适用性评审。

因此，当前参考库可支撑术语、通用开发、文档结构、配置管理和测试规则的候选生成，但 GJB 9432-2018 与 GB/T 8566-2022 的完整受控文本尚未闭合。不得据此声明完整 GJB 流程符合性。

缺失材料的已核实入口：

- GJB 9432-2018：目前只验证到[三页公开预览](https://www.instrument.com.cn/download/shtml/1362446.shtml)；购买时必须核对完整 11 页、标题和引用文件；
- GB/T 8566-2022：[国家标准元数据页](https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=1196DB510493E4E57EC6796598E75CDA)不公开全文；[中国标准出版社正版详情页](https://www.spc.org.cn/online/9f7d2faeb2dd3e15091b9cce22bdc5d4.html)可购买。

## 使用规则

1. 先读本目录清单，再按任务读取相应结构化 Markdown；需要确认原意时查看 PDF 页面。
2. 公开预览重建件只可用于候选规则提取和交叉核对，不得描述为发行机构权威电子原件。
3. OCR 可能有形近字、标点和阅读顺序错误；不得仅凭 OCR 文本下正式条文结论。
4. `missing` 标准涉及的开发、测试、配置或符合性结论必须明确标为阻塞或待适用性复核。
5. 替换任何 PDF 时必须同步更新 Markdown 来源说明、`standards.json`、自动检查和受影响文档引用。
