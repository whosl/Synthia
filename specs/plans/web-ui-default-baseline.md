# 默认 WebUI 基线

2026-09-26，用户确认当前定版界面固定到 `main`，并同步所有 worktree 的前端。

- `main` 的 `web/` 为默认前端基线，采用已上线并确认的三栏工作区、项目内审批、多标签文件/波形查看、紧凑项目卡片和自进化总览。
- 页面不展示 v-astrys 试版标签；项目类型位于卡片顶部，项目编号不在卡片中展示。
- 同步包含前端源码、测试、构建配置和 `web/bun.lock`。各开发分支的 Core、Runtime、Connector 与根依赖不随前端同步而变更。
- 后续合并旧分支时，应以此基线保留已确认的界面；独立新增能力需要集成到当前界面，避免直接恢复旧组件或覆盖整个 `web/`。
- `survey-repo-worktrees` 保留 `VITE_PLATFORM_PREVIEW` 沙箱预览适配（动态子路径、hash 路由和后端代理前缀）；该差异只影响预览部署，界面仍采用默认基线。
- 前端定版不表示旧分支后端同时升级。波形采集、累计提效和任务接口的完整行为仍取决于该分支后端能力及权限；正式演示使用已验证的线上服务。

本次同步前的分支位置保存在 `backup/ui-default-20260926/*`，用于追溯旧版及恢复。
