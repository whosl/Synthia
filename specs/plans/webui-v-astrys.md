# WebUI v-astrys

2026-09-26。基于 Astryx 的设计方法，用现有 Vue / Reka UI 实现；没有引入 React，也没有复制 Astryx 源码。

参考：https://github.com/facebook/astryx/wiki/Design-Conventions

- 保留资产 / 多标签工作区 / Agent 三栏、审批权限、工程阶段及工具调用协议。
- 主题掌管外观，组件掌管结构：语义颜色、4px 间距、8/12/24px 角色圆角，控件 28/32/36px。
- 用间距表达分组，常用动作就近展示；低频细节按需展开。状态使用图标/文字与颜色共同表达。
- 项目目录：页面标题与创建动作 → 实时概况 → 搜索和类型过滤 → 项目卡片/列表 → 活跃任务。
- 工作区：统一全局导航、轻量项目工具栏，三块独立但紧邻的工作表面；保留拖动分栏、窄屏抽屉与全部文件标签。
- 自进化：效果与能力总览 → 技能列表及调用证据 → 按需展开管理控制。
- 明暗主题、键盘焦点、加载/空/错误状态、减少动效偏好都保留。
- 本版分支 webui/v-astrys；线上发布前保留旧版构建与 HTML 入口。

验证与发布：

- `bun run --cwd web check`、`bun run --cwd web build:golden` 通过；Web 584 项测试通过。
- 浏览器检查项目目录、工程工作区、自进化页，在 320、390、800、1024、1280、1440、1600px 下无页面横向溢出，无页面脚本异常。
- 真实 Core 数据验证：项目检索、卡片/列表切换、文件多标签、P21 VCD 读取和缩放、运行记录、技能选择和提效口径展开。
- 工程项目审批入口、历史资料与移动端抽屉使用隔离 mock 验证，不提交真实审批或运行任务。
- 本地只读服务凭证对部分项目的任务/工具汇总无访问权限，验证时确认错误提示和不完整计数仍正常呈现；不改变授权规则。
- 发布仅移植本 UI 提交到现有线上版本，保存旧 HTML 和构建；不携带同时开发的 Connector 改动。
