# Synthia 统一项目页 v3 规格（grill 定稿）

- 状态：已确认（2026-08-16 grill 十二问定稿）
- 上游：specs/ui-redesign-v1.md（分层原则）、v2（术语）继续有效；本文取代统一页 v2 布局（B+就地审批卡版）
- 前置依赖标注：〔准直播〕=可先用 3s 轮询实现，真流式需 Runtime SSE 端点；〔打断〕=需 Runtime abort+重 prompt 组合

## 1. 灵魂：对话+工程双主体

页面 = 顶部状态带 + 全宽对话流 + 底部审批抽屉。无右栏。IDE 心智：对话是编辑器，状态带是侧栏。

## 2. 布局

```text
┌──────────────────────────────────────────────────────┐
│ 状态带（常驻，紧凑）                                    │
│ [任务切换器 ▾] │ G1✅G2🟡G3⬜G4⬜ │ B0✓B1○ │ 当前动作一句话 │
│ （记录面板与进化历史的入口也收在状态带，点击展开下拉）        │
├──────────────────────────────────────────────────────┤
│ 对话流（主体，占满剩余空间）                             │
├──────────────────────────────────────────────────────┤
│ 底部审批抽屉（等待时滑出，半屏高，批准/驳回后收起）          │
└──────────────────────────────────────────────────────┘
```

## 3. 对话流（核心交互）

- **流式输出**〔准直播〕：Agent 的叙述与工具调用按发生顺序实时出现（轮询 audit 增量渲染；真流式后续换 SSE）。等待期永远是活跃的：新工具条 3 秒内可见。
- **可插话**：输入框在 Agent 运行时不锁死。新消息默认入队（下一工具间隙生效=steer）；输入框旁有「直接插入」按钮〔打断〕：abort 当前轮 + 立即以新消息重新 prompt，打断动作在流内留标记卡。
- **内容形态**：用户气泡（右）/ Agent 叙述（左，永远直接可见不折叠）/ 工具条（四态+耗时）/ 产物卡片（点开右侧滑出抽屉阅读）/ 状态事件卡（「✓ 需求审查已通过」）/ 进化提示卡（「应用了经验 #42」「已沉淀新经验」）/ 失败=对话式汇报（Agent 陈述卡在哪、建议什么；不弹窗不结构化按钮）。
- **代码折叠规则**：叙述文本永不折叠；>15 行代码块折叠为代码卡；工具原始输出默认折叠。

## 4. 顶部状态带

- 任务切换器（多任务并存，后台继续跑，切换只换对话流内容）；
- 门状态紧凑序列（G1✅G2🟡…，hover 展开中文名与详情）+ 里程碑徽章（B0✓B1○）；
- 「当前动作」一句话（「行为审查等待批准」「RTL 生成中 · 已 2 分钟」）；
- 状态带可展开面板：运行记录（工具运行+证据，L3 内容只在这里）。

## 5. 底部审批抽屉

- 触发：run awaiting_approval 且 submission in_review；
- 内容：待审产物列表（快照成员，GJB 文档名，逐份可展开 markdown 阅读区，抽屉半屏高优先阅读舒适）；
- 操作：里程碑门「✓ 批准并建立 B? 里程碑」（baseline_id=bl-<gate>-<ts>），非里程碑「✓ 批准」；驳回理由必填；批准失败（如 active 基线冲突）显示人话原因与建议；
- 批准后抽屉收起，流内出现「✓ 已批准 🏁 已建立 B? 里程碑」事件卡，Agent 自动续跑；
- Skill 进化提案复用同一抽屉交互（人审）。

## 6. 空项目首屏

对话框居中（ChatGPT 新会话式），下方 3-4 个示例任务卡片一键填入（如「设计一个 UART 收发器…」）。

## 7. 多任务

并存多会话；状态带切换器管理；每任务独立对话流与审批状态。

## 8. 审批中心（全局）保留

跨项目「等我批」聚合队列，快速清空场景用；项目内审批仍是主路径。

## 9. 自我进化（双层）

- 自动层（无感）：任务结束后经验沉淀入知识库（修过的 bug 模式/有效约束写法/门禁反馈），后续任务自动检索复用；流内提示应用与沉淀；
- 人审层：Skill 模板/检查项变更 → 提案 → 底部审批抽屉人审 → 生效；
- 独立「进化」页：知识库浏览、提案队列、进化统计（复用/命中率）。

## 10. 交付时刻

任务完成（码流+G4 批准）：流内大成功卡（码流 sha/大小/证据链/下载入口）+ 自动生成《交付摘要》（本次门禁记录/关键决策/证据清单，可导出，作为 GJB 交付物）。

## 11. 错误人话化

所有等待/失败状态显示人话 + 可操作（「Agent 正在处理，已等待 2 分钟」「runtime 请求超时，点击重试」）；关联号/错误码只在记录面板可见。

## 验收标准

1. 等待期 3 秒内可见新事件（准直播）；输入框运行时不锁死；「直接插入」产生打断标记卡并生效。
2. Agent 叙述在对话流中永远不折叠；代码卡折叠仅作用于代码块。
3. 状态带常驻且包含任务切换器/门序列/里程碑/当前动作；记录面板为状态带展开项。
4. 审批抽屉满足 §5 全部行为；批准失败有人话提示。
5. 空项目首屏为居中对话框+示例卡。
6. 失败为对话式汇报（无弹窗无按钮组）。
7. 旧路由继续重定向到统一页。
8. build 零错误；前端测试覆盖上述可测点。
