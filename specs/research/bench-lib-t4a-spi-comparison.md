# SPI 主控制器（T4a spi）：黄金基线 vs 盲测对比报告

- 设计：FreeCores spi（出题卡：bench-lib/spi，主控制器子题；从机拓扑/多主/DMA/Quad 不在范围）
- 项目：p40（黄金基线，参考适配）/ p41（盲测，用户消息式输入、从零实现）
- 日期：2026-10-20 ~ 10-24；器件统一 xc7k160tffg676-1（160T，50MHz 单时钟域）
- 需求：SPI-MST-REQ v1.0 + spi-constants v1.0（含勘误 E1-E7 全量）；统一判据：(k) SPI_KBPS ≥ 3000（digest 判）、WNS ≥ 0、LUT ≤ 4000 / FF ≤ 3000 / BRAM ≤ 8 / DSP ≤ 4
- 终态：双侧四步全绿 + 双侧 DRQ 矩阵 + 复述关二次保险丝生效（E1-E7 零复发，新暴露 A-05/OBS-1）

|---|---|---|
| validate | ✅ | ✅ 语法/展开 0 错 |
| simulate | ✅ TB-PASS（TB 链 5 轮归档） | ✅ PASS a..k errors=0（warning 8 良性） |

## 二、面积/时序/吞吐对照（同 160T 同 50MHz）

| 维度 | 黄金 p40 | 盲测 p41 | 差 |
|---|---|---|---|
| LUT（routed） | **484** | 588 | 黄金小 1.22× |
| FF | **236** | 623 | 黄金小 2.64× |
| BRAM/DSP | 0 / 0 | 0 / 0 | 同 |
| WNS@50MHz | +13.043 | **+14.526** | 双侧大裕量，无鉴别力 |
| SPI_KBPS | **49817** | 48681 | 盲测 97.7%，差值=E6 怪癖（黄金末位压缩 L-1 周期 vs 盲测合规完整 L 周期）+字符间释放窗略宽，皆规范允许 |
| RTL 行数 | 967（参考 794 + 适配 173，含 defines） | **627**（4 件） | 盲测省 35% |
| TB 行数 | 512 | **911** | 盲测 1.78×（场景插桩更重） |

**形态**：面积黄金显著小（参考的 32 位移位通路+紧凑计数器 vs 盲测双 128 位移位器+8×32 寄存器堆的直白微架构）；盲测时序裕量反而更大。吞吐差完全可归因——**E6 裁定（末位压缩为参考怪癖、不作判据）在本件得到定量验证**：97.7% ≈ 完整 L 周期的合规代价，零真实设计赤字。

## 三、覆盖对齐程度

- 双侧 DRQ→证据矩阵齐全（p40 27 行 / p41 baseline-summary v1），全部达标
- 判卷不同卷（延续 T3 结论）：双侧 TB 均为独立从机模型+独立寄存器参考模型，验收面同源（附录 A + (k) 判线）
- 复述关清单（A-01 int 电平 / A-02 场景 j 重释 / A-03 度量面窗口 / A-04 RX 复位 0 / A-05 启动双路径 / OBS-1 编辑性残留）全部操作者裁定后冻结——**A-05（写 TX[0] 触发与 GO 置 1 并存）是附录真实的欠指定点**，黄金侧参考实现天然自洽故未暴露，盲测从零复述时逼问出来

## 四、分歧台账对照（保险丝双暴露）

| 侧 | 分歧族 | 性质 |
|---|---|---|
| 黄金 p40 | D-1..D-17：E1 真值表换位、E2 CPOL 范围、E3 忙写丢弃、E4 SS 释放窗、E5 多字拼接序、E6 末位压缩、E7 CHAR_LEN=0 别名、D-17 度量面常量 10× | **模板/附录勘误 7 处 + 参考怪癖 3 处 + TB 度量面 1 处**，全部裁定后冻结，E1-E7 进模板 |
| 盲测 p41 | G1 呈现序 off-by-one、G2 检查早于尾迹、G3 半周期测量面、G4 中断遗留、G5/G5′ (k) 期望派生自不完备视图 | **全部 TB 侧，DUT 零缺陷**（8 轮 TB 迭代 RTL 一次未修） |

**E1-E7 在盲测侧零复发**——黄金侧暴露的模板勘误经修订后向盲测传递成功率 100%；盲测侧暴露的新类别只有"附录欠指定"（A-05）与"编辑性残留"（OBS-1），无一处与黄金侧重叠。

## 六、关键发现

1. **G5′ 是新 TB 缺陷类：期望派生自不完备后门视图**——`u_tx.mem` 是装载拍快照 ≠ 寄存器输出线并集，期望面锚错了存储面。教训：F-02 反门契约必须声明快照语义（装载拍 vs 实时）；黄金侧的反门等价但语义不同，两侧各自自洽、互不复发
2. **停止规则第一次实战生效**：3 轮 FAIL 即停、归因报告替代第 4 轮盲试，把"凑绿"风险关进流程；G5′ 的算术级闭环（0x2383FCC7 = pat32(511,3) 逐步 mod 2³² 验算）是停轮换来的
3. **跨侧教训传递有效**：黄金侧 D-17（度量面常量 10×）在盲测 A-03 裁定中附量纲对账要求，盲测 TB 直接落了 DIM_CHECK 行——同类缺陷零复发
4. **协议/控制型设计盲测 DUT 零缺陷**与 T3 openmsp430 结论一致：模型在此类设计上 RTL 一次成型；全部迭代消耗在 TB 期望面（两侧合计 15 版 TB，RTL 侧仅参考怪癖 1 补丁）
5. **A-05 暴露附录欠指定的新模式**：参考实现天然消歧的点（双触发路径）在从零实现时必须显式裁定——复述关对此类问题的捕获先于任何仿真轮，是成本最低的保险丝

## 七、T4 首件结论

spi 作为 T4 再验证轮首件：双侧同考卷四步全绿，模板经 E1-E7 勘误后向盲测传递零复发，方法论闭环完整（黄金侧暴露→勘误冻结→盲测复述→新类别捕获→算术级归因→停止规则→裁定放行）。**质量面：盲测 8 轮 TB 迭代 DUT 零缺陷 + 吞吐差 2.3% 全可归因，是四轮（T2/T3/T4a）以来盲测侧最干净的一件。** 面积面：黄金参考仍小（LUT 1.22×/FF 2.64×），人类参考在紧凑度上的优势延续。
