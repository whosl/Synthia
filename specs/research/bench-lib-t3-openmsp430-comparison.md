# MSP430 兼容 CPU 核（T3 openmsp430）：黄金基线 vs 盲测对比报告

- 设计：openmsp430 CPU-core 子题（出题卡裁剪修正：参考树无核内 timer/uart，子题=CPU 核本体）
- 项目：p35（黄金基线）/ p36（盲测，用户消息式输入）
- 日期：2026-10-12 ~ 10-14；器件统一 xc7k160tffg676-1（160T，50MHz 单时钟域）
- 需求：MSP-CORE-REQ v1.0 + msp430-isa.md（27 核心指令/7 寻址模式/SR V=bit8/(k) CORE_CYCLES≤400,000）
- 终态：双侧四步全绿 + 双侧 DRQ 覆盖矩阵（收官后补件）+ 一处黄金侧度量缺陷被复核抓出并修复

## 二、面积/时序对照（同 160T 同 50MHz）

| 维度 | 黄金 | 盲测 | 差 |
|---|---|---|---|
| LUT | 1,985 | 1,515 | **−23.7%**（盲测小） |
| FF | 688 | 444 | **−35.5%**（盲测小） |
| DSP | 1 | 0 | 盲测零 DSP |
| BRAM | 8 | 16 | 黄金小（存储几何：盲测统一 512Kb vs 黄金分区 256Kb 级） |
| WNS | +2.759 | +6.225 | **盲测裕量反超 2.3×** |
| CPI 类 | ≈1.0（1,853 指令/1,852 拍） | 低 CPI 多周期（4,010 拍跑完 A.5 基准） | **口径注意：两侧程序不同，周期数不可直比**；CPI 量级同类 |

**三件 T3 首次盲测双维全胜**（面积+时序同时占优）。与 jpeg（17× DSP 差换吞吐）、USB（LUT/FF 互有胜负）构成谱系：**对比形态由设计类型决定，不存在单一方向的"模型更省/更费"**。

## 三、覆盖对齐程度（本件特有章节——用户质询触发）

**结论：需求层面对齐（双侧 25/25 DRQ 矩阵全达标），判卷层不同卷（与 USB 案同构），交叉验证未做。**

1. **DRQ 覆盖矩阵**：双侧收官后各补 25 行全表（TST-003 补件），全部达标。盲测侧如实申报四笔覆盖缺口：算术族 .b 未定向（间接覆盖）、DADD 仅 .w、JMP 满幅 ±1024 未构造（实测 +447/−25 两向）、PB 侧 8 条无独立 chk（PD 承担）
2. **判卷程序结构性不同**：p36 逐字跟 A.5（装载 0x0200/插入排序/S1-S7）；p35 三处工程化偏离（基址 0xC000/冒泡/中断双挂）——文档化但不同卷
3. **黄金侧度量缺陷（操作者复核抓出，勘误 No.25）**：TB 的 CORE_CYCLES 计数无 halt 门控、DIGEST 在看门狗窗满才打 → 旧值 299,999=窗长−1 是假的。修复=halt 门控+提前打印 → 真实值 **1,852**（RTL 零改动，r19 复跑全绿）。**教训与 H34 同族：性能数字的度量面本身必须被验证；本例是我（操作者）验收时未核度量逻辑，收官后复核才抓出**
4. 交叉验证（黄金 TB × 盲测核）未做——CPU TB 为反门装载+双跑引擎，适配成本中等；本件以"双侧矩阵+度量修复"收口，交叉留作后续可选

## 五、关键发现（T3 数据点）

1. **CPU 核是模型的主场**：从零实现 MSP430 ISA（27 指令×双宽度×7 模式+中断），盲测面积/时序双优——控制密集型设计上模型的代码密度优势直接转化为物理优势
2. **R8 缺陷（17 位取反 `~{1'b0,b}` vs `{1'b0,~b}`）是经典位宽陷阱**——VCD 拍级铁证定罪；同族还有 R16（操作码映射错误断言"写检查时未验算"——会话自我纠错留痕）
3. **R22（SR 标志回写吞 GIE）隐蔽性极高**：功能指令全绿、仅中断链死锁——23 万拍静默拒纳的定罪靠的是"flags[7:3]≡0 探针实证 + SLAU049 '标志更新不动控制位'语义对照"
4. **黄金侧也会度量撒谎**（No.25）：四步全绿的性能数字若无 halt 门控就是窗长常数——**验收不能只看"有 DIGEST 行"，要看度量逻辑本身**
5. 会话自愈能力显著：TB 污染后从 git 对象恢复基底重建（v8→v9/v10），未丢链

## 七、结论

openmsp430 五步闭环（需求→黄金→盲测→度量复核修正→报告）完成。核心数据：**同一份考卷，盲测以 −23.7% LUT / −35.5% FF / 0 DSP / 2.3× 时序裕量全面超过参考实现**；功能双侧全绿且 DRQ 矩阵双 25/25；黄金侧一处度量缺陷被复核抓出修复（299,999→1,852）。T3 三件（jpeg/usb/msp430）至此形态谱系完整：面积与吞吐的权衡方向由设计类型决定，模型在控制密集型设计上优势最大。
