## 1. 范围

### 1.1 标识

- 项目标识：CAN-BSC（Synthia 基准库盲测 T2）
- 产品名称：CAN 总线控制器可编程逻辑器件软件（PLDS），顶层标识 `can_top`
- 目标器件：Xilinx Kintex-7，型号 xc7k70tfbv676-1
- 适用阶段：G0～G4（需求、设计、RTL 基线）

### 1.2 系统概述

本 PLDS 实现一个 CAN 2.0B 协议控制器（BasicCAN 功能子集，SJA1000 兼容寄存器模型）：处理器侧经 8 位宽同步寄存器总线访问一组控制和状态寄存器，经发送缓冲区发起帧发送、经接收缓冲区读取收到的帧；串行侧经 CAN 总线收发器接口（tx/rx 两位信号 + 收发器使能）参与总线仲裁和通信。支持标准帧（11 位标识符）与扩展帧（29 位标识符）的收发、数据帧/远程帧、位填充与解填充、CRC-15 校验、应答处理、错误检测与错误计数（TEC/REC）及 bus-off 离线判定、可编程位定时（三段：同步段/传播段/相位缓冲段，含重同步宽度）、双验收滤波器（代码/掩码对）。CAN 2.0B 协议规范性定义（帧格式、位编码、仲裁、错误处理规则、位定时术语）以 Bosch CAN 2.0B 规范为准，本文不复述。PeliCAN 模式、监听-only 模式、睡眠模式、单边沿采样模式不在范围内。

## 3. 功能要求

### 3.1 寄存器空间（规范数据，SJA1000 BasicCAN 模型）

| 地址 | 寄存器 | 读写 | 复位值 | 位定义 |
|---|---|---|---|---|
| 0x00 | CR | RW(部分) | 0x01 | bit0=RR（复位请求，1=进入复位态），bit1=RIE（接收中断使能），bit2=TIE，bit3=EIE（错误中断使能），bit4=OIE（溢出中断使能），其余保留读 0 |
| 0x01 | CMR | W | — | bit0=TR（发送请求），bit1=AT（中止发送），bit2=RRB（释放接收缓冲），bit3=CDO（清除数据溢出），bit4=GTS？不用，保留写 0 |
| 0x02 | SR | R | 0x0C | bit0=RBS（接收缓冲满），bit1=DOS（数据溢出），bit2=TBS（发送缓冲释放），bit3=TCS（发送完成），bit4=RS（接收中），bit5=TS（发送中），bit6=ES（错误态：TEC/REC>96 或 bus-off），bit7=BS（bus-off） |
| 0x03 | IR | R（读清零语义） | 0x00 | bit0=RI（接收中断），bit1=TI，bit2=EI（错误警告中断），bit3=DOI（数据溢出中断），bit4=WUI 不用读 0，bit5=EPI（错误消极中断），bit6=ALI（仲裁丢失中断），bit7=BEI（bus-off 中断） |
| 0x04 | ACR | RW | 0x00 | 验收代码（复位模式下可写） |
| 0x05 | AMR | RW | 0xFF | 验收掩码（1=不比较该位） |
| 0x06 | BTR0 | RW | 0x00 | bit7=SJW-1（重同步宽度），bit5:0=BRP-1（波特率预分频） |
| 0x07 | BTR1 | RW | 0x00 | bit7=采样次数（0=单次，1=三次），bit6:4=TSEG2-1，bit3:0=TSEG1-1 |
| 0x08 | OCR | RW | 0x00 | bit1:0=OCPOL/OCTN0…输出控制简化为：bit0=TX 极性（0=正常），其余保留 |
| 0x09 | AL | R | 0x00 | 仲裁丢失位置（位编号） |
| 0x0A | ECC | R | 0x00 | 错误码捕获（错误类型+方向+段位置，格式见设计说明） |
| 0x0B | EWLR | RW | 0x60 | 错误警告限（默认 96） |
| 0x0C | RXERR | R | 0x00 | 接收错误计数（复位模式下可读） |
| 0x0D | TXERR | R | 0x00 | 发送错误计数 |
| 0x1F | CDR | RW(部分) | 0x00 | bit7=扩展帧模式（1=29 位 ID 收发使能，即需求 1.2 扩展帧授权），bit3:0=时钟分频（本设计单时钟域，仅接受写 0） |
| 0x0A-0x13 | TX 缓冲 | W | — | 工作态写入：描述符 2 字节 + 数据 ≤8（发送窗口） |
| 0x14-0x1D | RX 缓冲 | R | — | 工作态读取：接收 FIFO 窗口（描述符 2 + 数据 ≤8，10 字节同构） |
| 0x09-0x0D | AL/ECC/EWLR/RXERR/TXERR | R/部分RW | 见各行 | 基本视图（CDR.7=0）读 0；扩展视图（CDR.7=1）按 SJA1000 暴露真值（EWLR 复位 0x60、错误计数复位 0） |

未定义地址（0x0E、0x0F-0x09 之外的非映射区）读回 0x00，写忽略。**极性/复位值以 SJA1000 数据手册为准，黄金基线阶段双源实证。**

| 编号 | 要求 | 关键度 |
|---|---|---|
| CAN-DRQ-FUN-001 | 寄存器读写经处理器侧总线单周期完成（零等待）；上表地址、位定义、读写属性与复位值逐项实现；复位请求 RR=1 期间方可写 ACR/AMR/BTR0/BTR1/OCR/EWLR，RR=0 期间写这些地址被忽略。 | 关键 |
| CAN-DRQ-FUN-002 | 软复位语义：RR=1 → 控制器进入复位态（不参与总线、错误计数清零、SR=复位值）；RR 0→1→0 后按当前配置重新上线。 | 关键 |
| CAN-DRQ-FUN-003 | 位定时：CAN 位速率由 BTR0/BTR1 编程，t_SCL = 2·(BRP)·(1+TSEG1+TSEG2)/f_clk（BRP/TSEG 为寄存器+1 值）；重同步宽度 1..4 tq 经 SJW 编程；支持三段位结构（SYNC/PROP+P1/P2）。 | 关键 |
| CAN-DRQ-FUN-004 | 发送：CPU 写发送缓冲（帧信息：DLC/ID/RTR + ≤8 字节）→ CMR.TR=1 → 控制器组帧（SOF/仲裁/控制/数据/CRC/ACK/EOF/IFS）并送上总线；发送成功后 SR.TCS=1、TBS=1，TI 置位；发送缓冲未释放时再写视为覆盖。 | 关键 |
| CAN-DRQ-FUN-005 | 仲裁：发送期间在仲裁段逐位比较，遇显性覆盖隐性（丢仲裁）即退出发送、转接收，AL 记录丢失位位置，ALI 置位；总线空闲后自动重发（除非 AT 中止）。 | 关键 |
| CAN-DRQ-FUN-006 | 接收与验收滤波：总线上的帧经 ACR/AMR 滤波（ID 逐位与代码比较，掩码位跳过），通过者移入接收缓冲，RBS=1、RI 置位；CPU 读毕 CMR.RRB=1 释放缓冲；缓冲未释放时新帧到达置 DOS=1、DOI 置位，新帧丢弃。 | 关键 |
| CAN-DRQ-FUN-007 | 远程帧：收到 RTR=1 的帧按同一滤波规则入接收缓冲（RTR 位随描述符可读）；发远程帧的应答机制同数据帧。 | 重要 |
| CAN-DRQ-FUN-008 | 位编码：仲裁/控制/数据/CRC 段NRZ + 位填充（连续 5 同值位后插入补码位）；接收侧解填充；EOF/IFS/错误/过载帧定界符区不填充。 | 关键 |
| CAN-DRQ-FUN-009 | CRC-15：生成多项式与初值按 CAN 2.0B 规范，覆盖 SOF 至数据段（填充后位流），发送侧生成、接收侧校验，校验错发错误帧。 | 关键 |
| CAN-DRQ-FUN-010 | 应答：发送侧在 ACK 槽发送隐性位，检测到显性位才算 ACK 成功；无 ACK 计发送错误并重发。接收侧对通过 CRC 的帧在 ACK 槽回显性位。 | 关键 |
| CAN-DRQ-FUN-011 | 错误处理：按 CAN 2.0B 规则维护 TEC/REC——发送错误 +8（主动错误下递增规则含 +8/重启动 +12 等）、接收错误 +1、正确收发递减；任一计数 >127 → 错误消极（ES=1）；TEC ≥ 256 → bus-off（BS=1、退出总线，仅 RR 复位序列后经 128×11 隐性位恢复）；错误帧（6 连续显性主动错误标志）与错误码捕获 ECC 按规范产生。 | 关键 |
| CAN-DRQ-FUN-012 | 过载帧：接收侧在满足条件时发送过载帧（6 显性 + 8 隐性定界符），规则按规范。 | 重要 |
| CAN-DRQ-FUN-013 | 中断：IR 各位按事件置位；对应 CR 使能位开放时 irq 输出有效（电平）；IR 读操作清零全部已置位位。 | 重要 |
| CAN-DRQ-FUN-014 | 中止发送：CMR.AT=1 → 当前发送中止（等待退出的位流窗口），SR.TCS 反映中止完成，发送缓冲释放。 | 重要 |
| CAN-DRQ-FUN-015 | 时钟分频寄存器 CDR（0x1F）：bit7 为扩展帧模式选择（置 1 后 AL/ECC/EWLR/RXERR/TXERR 与 29 位 ID 收发生效），bit3:0 分频位仅接受写 0（单一时钟域）。 | 关键 |

## 9. 测试要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| CAN-DRQ-TST-001 | 自检 TB 以寄存器访问任务模拟处理器侧驱动 DUT，串行侧挂 CAN 总线行为模型（可编程：回 ACK/不回 ACK、注错位、发起竞争帧、回远程帧），位级线与（显性 0 胜）；期望值由 TB 内建参考模型产生，不得取自 DUT。失败 `$fatal` 并打印场景号、期望与实际；全过打印 PASS。 | 关键 |
| CAN-DRQ-TST-002 | 必测场景：(a) 复位默认值与软复位序列；(b) 标准数据帧收发（写 TX 缓冲→TR→总线模型逐位比对→TCS/TI、模型侧注入帧→滤波通过→RX 读取 RRB 释放）；(c) 扩展帧（29 位 ID）收发；(d) 验收滤波（通过/拒绝/掩码无关位）；(e) 仲裁丢失（模型同时发更优先 ID）→AL 位置+自动重发成功；(f) 位填充/解填充等价（长同值数据帧逐位流比对）；(g) CRC 校验（模型注入 CRC 错位→DUT 发错误帧、错误计数变化）；(h) ACK 缺失（模型不回 ACK）→重发、TEC 增长；(i) 错误计数与 bus-off/恢复序列；(j) 位速率三档实测；(k) 溢出（不释放缓冲连收两帧）→DOS/DOI；(l) 远程帧收发与自动应答；(m) 中断链路（使能门控、IR 读清）。 | 关键 |
