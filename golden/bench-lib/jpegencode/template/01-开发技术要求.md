## 1. 范围

### 1.1 标识

- 项目标识：JPEG-ENC（Synthia 基准库盲测 T3）
- 产品名称：JPEG 基线顺序模式编码器可编程逻辑器件软件（PLDS），顶层标识 `jpeg_top`
- 目标器件：Xilinx Kintex-7，型号 xc7k70tfbv676-1
- 适用阶段：G0～G4（需求、设计、RTL 基线）

### 1.2 系统概述

本 PLDS 实现一个 JPEG 基线顺序模式（baseline sequential DCT, huffman）压缩引擎：像素侧接受 24 位 RGB 光栅流（按行扫描）；变换链为 RGB→YCbCr 色彩变换 → 三分量（Y/Cb/Cr，4:4:4 采样）8×8 分块 DCT → 各分量量化 → 之字序重排 → DC 差分预测 + AC 游程编码 → 标准霍夫曼熵编码（ITU T.81 Annex K 的示例表，亮度/色度各一套 DC+AC 表）→ 字节流；输出侧为 JPEG 熵编码数据流（文件头/标记段不在范围内，由主机侧生成）。DCT 系数精度：8 位像素输入、11 位中间精度、输出量化系数按量化表除法结果。ITU T.81 的规范性定义（DCT 数学定义、之字序、霍夫曼编码程序、字节填充 0xFF/0x00 规则）以标准为准，本文不复述。渐进模式、算术编码、4:2:0/4:2:2 下采样、无失真模式不在范围内。

### 1.3 基线

本文件为唯一需求输入基线（含附录 A/B 规范数据）；下游文档由本文件派生。任务要求以 `JPEG-DRQ-*` 唯一标识。

## 3. 功能要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| JPEG-DRQ-FUN-001 | 色彩变换：RGB→YCbCr 按 BT.601 定点矩阵实现（系数见附录 A.1），输出无符号偏移二进制（Y/Cb/Cr 各 8 位，范围 [0,255] 中点 128 的偏移约定按 T.81 §A.3 与附录 A.1）；4:4:4 采样，三分率像素一一对应。 | 关键 |
| JPEG-DRQ-FUN-002 | 分块：每分量按 8×8 像素块切分；图像宽高非 8 倍数时**边缘块按边界像素复制扩展**（T.81 §A.2.3 边界重复规则），扩展不产生额外输出像素。 | 关键 |
| JPEG-DRQ-FUN-003 | DCT：每 8×8 块做二维前向 DCT（T.81 §A.3.3 的 FDCT 数学定义）；实现精度要求：经 IDCT 重建后（独立参考 IDCT），8 位像素输入下重建误差峰值 ≤ ±2（类 MPEG-1 测试条款）。 | 关键 |
| JPEG-DRQ-FUN-004 | 量化：Y 与 Cb/Cr 分别使用附录 A.2 的标准量化表（线性量化，四舍五入）；量化系数用带符号定点表示（11 位幅度内）。 | 关键 |
| JPEG-DRQ-FUN-005 | 之字序：块内 64 系数按 T.81 §A.6 图 A-6 的之字扫描序重排后进入熵编码。 | 关键 |
| JPEG-DRQ-FUN-006 | DC 预测：每分量块间 DC 系数做差分（与同分量前一块的 DC 之差），差值按 T.81 §F.1.2.1 分类编码。 | 关键 |
| JPEG-DRQ-FUN-007 | AC 游程：块内 63 个 AC 系数生成（游程长度 RUN, SIZE）符号对；全零 AC 块输出 EOB；16 连零输出 ZRL（T.81 §F.1.2.2 与 §F.1.2.3）。 | 关键 |
| JPEG-DRQ-FUN-008 | 霍夫曼编码：DC 差值与 AC 符号对按附录 A.3 的标准霍夫曼表（ITU T.81 Annex K Table K.3/K.4/K.5/K.6）编码；**表内容必须按附录 A.3 原文实现**（位串与码长逐项），不得凭记忆重构。 | 关键 |
| JPEG-DRQ-FUN-009 | 位流组装：霍夫曼码与幅度附加位按 T.81 §F.1.2.3 规则串接（负数幅度取反码-1 最低位）；字节装配 MSB 在前；**0xFF 字节后必须插入 0x00 字节填充**（T.81 §B.1.1.5）。 | 关键 |
| JPEG-DRQ-FUN-010 | 数据流控制：像素流式输入带 valid 背压握手；编码器内部块缓冲不得丢失或重复像素；`end_of_frame` 输入脉冲声明最后一行，帧尾自动冲刷全部流水（含部分填充块按 FUN-002 规则补齐）。 | 关键 |
| JPEG-DRQ-FUN-011 | 三分量并行/流水安排为实现自由；但**输出字节流必须按 T.81 §B.2.3 的扫描交错序**（每块一个 MCU=1 个 Y 块 + 1 个 Cb 块 + 1 个 Cr 块，4:4:4 下每 MCU 三块按 Y,Cb,Cr 顺序）。 | 关键 |
| JPEG-DRQ-FUN-012 | 复位释放后确定空闲态；内部状态（DC 预测器、块缓冲、位装配器）全部清零；无残留跨帧状态。 | 关键 |

## 9. 测试要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| JPEG-DRQ-TST-001 | 自检 TB 以像素流驱动 DUT，输出字节流与 TB 内建独立参考编码器逐字节比对（参考用高级语言精确算术预生成或内建行为模型，不得取自 DUT）；失败 `$fatal` 打印场景号、字节偏移、期望与实际；全过打印 PASS。 | 关键 |
| JPEG-DRQ-TST-002 | 必测场景：(a) 复位确定性与空闲握手；(b) 单 8×8 块纯色（全 128/全 255/全 0——DC-only 编码路径、极端幅度）；(c) 水平/垂直渐变块（AC 主频分量）；(d) ≥2 个完整 MCU 的确定性伪随机图像（全链路 RGB→字节流逐字节）；(e) 非 8 倍宽高（如 12×9——边界扩展路径）；(f) 0xFF 填充注入（构造必产 0xFF 的量化模式验证 0x00 填充）；(g) DC 差分链（连续块 DC 单调序列）；(h) EOB/ZRL 路径（构造全零 AC 块与长零游程块）；(i) 帧尾冲刷（不满块补齐 + 位装配器 1 补齐）；(j) 背压间歇（out 消费暂停/恢复不丢失字节）；(k) 稳态吞吐测量（PERF-002 验收）：持续灌入 ≥256 像素，统计 pix_ready 占空比并断言稳态 ≥1 像素/拍，打印 `CYCLES_PER_PIXEL <n>` 行进仿真日志供 digest 判定——本场景不过则 PERF-002 判 FAIL，不得以功能场景通过替代。 | 关键 |
| JPEG-DRQ-TST-003 | 每条需求规定验证方法并双向可追溯。 | 关键 |
