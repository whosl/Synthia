# SDR SDRAM 控制器 — 开发技术要求

- 文档编号：SDR-SDC-REQ；版本 1.0（2026-10-25）
- 梯队：T4（再验证轮）；出题卡：bench-lib/sdram
- **统一器件：xc7k160tffg676-1（Kintex-7 160T，speed -1）**
- 规范基准：SDR SDRAM 器件公开数据手册（Micron TN-46/TN-47 类：命令真值表/初始化序列/刷新规格）。本文不复述协议数学语义，只引用行为要求；数据类常量（命令真值表/模式寄存器位图/时序周期数/地址映射）见附录 `std/sdram-constants.md`。**附录与器件手册出入按阻塞上报，不自行勘误**（转录保险丝：TB 场景全覆盖 + 黄金侧四步双暴露）
- 本文独立成篇：不引用任何参考实现的结构、命名或文件组织

## 1. 任务概述

实现一个 **SDR SDRAM 控制器**的可综合 RTL：面向 2M×32（8MB）SDR SDRAM 器件模型（附录 A.7 几何冻结），完成上电初始化状态机、命令发射（ACTIVE/READ/WRITE/PRECHARGE/AUTO REFRESH/MRS）、自动刷新调度与仲裁、8/16/32 位主机单次传输、模式寄存器装载路径。主机接口为 SRAM 型同步握手（busy 忙等待），一次一个传输。

范围外（明确不做）：突发传输（Burst，BL 冻结 1）、时钟使能/掉电模式（器件模型无 CKE）、自刷新进入/退出（Self-Refresh）、多片选、主机侧双向数据总线复用选项、Burst Terminate 命令。

## 2. 术语

| 术语 | 含义 |
|---|---|
| ACTIVE | 行激活命令（锁定 bank+row） |
| PRECHARGE | 行预充电（关闭行；A10=1 为全 bank） |
| AUTO REFRESH | 自动刷新命令（器件内部行计数器自增） |
| MRS | 模式寄存器装载命令 |
| close-page | 每次传输完成后即 PRECHARGE 关行的策略（本子题冻结） |
| tRCD/tRP/tRAS/tRC | 行选通到列命令/预充电恢复/行活跃/行周期（A.5 周期数冻结） |
| lane | 8/16 位访问在 32 位总线上的数据通道选择（A.4） |

## 3. 功能需求

| 编号 | 需求 | 级别 |
|---|---|---|
| SDC-DRQ-FUN-001 | **上电初始化序列**：复位释放后按附录 A.3 顺序执行——上电等待（≥5000 周期 NOP）→ PRECHARGE ALL → AUTO REFRESH ≥2 次 → MRS（默认模式字按 A.2）→ 就绪；初始化全程 busy_l 保持"忙" | 关键 |
| SDC-DRQ-FUN-002 | **命令发射**：按附录 A.1 真值表驱动 sd_cs_l/sd_ras_l/sd_cas_l/sd_we_l/sd_a/sd_ba；ACTIVE 后满足 tRCD 才能发 READ/WRITE；READ/WRITE 的 A10=0（无自动预充）；时序参数全部按 A.5 周期数 | 关键 |
| SDC-DRQ-FUN-003 | **单次读传输**：主机请求（hb_cs_l+hb_rd_l 低，busy_l 高时被采样）→ 控制器完成 ACTIVE→READ→CL2 数据采样 → hb_dout 有效 → PRECHARGE 关行（close-page 冻结）→ busy_l 撤忙；数据经 DQM 全通（32 位） | 关键 |
| SDC-DRQ-FUN-004 | **单次写传输**：hb_wr_l 低被采样 → ACTIVE→WRITE（DQM 按 A.4）→ 写数据发射 → 满足 tDPL 后 PRECHARGE → busy_l 撤忙 | 关键 |
| SDC-DRQ-FUN-005 | **访问尺寸与 lane 语义**：hb_size 编码（0=32 位/1=8 位/2=16 位/3 保留）按附录 A.4；8 位 lane=hb_addr[1:0]、16 位 half=hb_addr[1]，**不做低位对齐**；DQM 生成规则按 A.4 | 关键 |
| SDC-DRQ-FUN-006 | **自动刷新调度**：按 A.6 规格（间隔 ≤781 周期均值口径）发起 AUTO REFRESH；与主机访问仲裁：访问进行中可推迟刷新，但两次刷新命令间隔 ≤2×781 周期；刷新执行期间 busy_l 拉忙；仲裁策略（抢先/插空）自定并在交付文档声明 | 关键 |
| SDC-DRQ-FUN-007 | **模式寄存器路径**：mode_set_l=0 的写事务不进存储阵列，而以 hb_din[10:0] 为模式字发 MRS（位定义按 A.2；本子题行为冻结 BL=1/顺序/CL=2，但 MRS 路径须对任意模式字完整发射）；tMRD 后恢复就绪 | 关键 |
| SDC-DRQ-FUN-008 | **复位**：sys_rst_l 同步低有效；复位后所有 SDRAM 命令信号回到 NOP 态（全高）、busy_l 忙、初始化序列重跑 | 关键 |

## 4. 性能需求

| 编号 | 需求 | 级别 |
|---|---|---|
| SDC-DRQ-PERF-001 | 系统时钟 50 MHz 单时钟域（SDRAM 器件模型同相时钟假设，TB 在同域建模） | 关键 |
| SDC-DRQ-PERF-002 | **访问延迟**：32 位单次读从请求被采样到 busy_l 撤忙且 hb_dout 有效 ≤ 20 周期——实测打印 `SDC_RLAT <n>`（digest 判 n>20 即 FAIL） | 关键 |
| SDC-DRQ-PERF-003 | **混合吞吐**：32 位写读交替连续流 ≥1024 次访问，等效带宽 `SDC_MBPS <n>` ≥ 8（digest 判 n<8 即 FAIL）；窗口含 close-page 全序列与刷新插入，口径按 TST-002(j) | 关键 |
| SDC-DRQ-PERF-004 | 时序收敛：50MHz WNS ≥ 0（clock-only XDC，NSTD-1/UCIO-1 豁免） | 关键 |
| SDC-DRQ-PERF-005 | 资源预算：LUT ≤ 3000、FF ≤ 2500、BRAM ≤ 4、DSP = 0 | 重要 |

## 5. 接口需求

| 编号 | 需求 | 级别 |
|---|---|---|
| SDC-DRQ-IF-001 | 顶层 `sdram_ctrl_top`：`sys_clk/sys_rst_l`；SDRAM 侧 `sd_cs_l/sd_ras_l/sd_cas_l/sd_we_l/sd_dqm[3:0]/sd_a[10:0]/sd_ba[1:0]/sd_dq_in[31:0]/sd_dq_out[31:0]`（数据单向两路）；主机侧 `hb_addr[22:0]/hb_din[31:0]/hb_dout[31:0]/hb_rd_l/hb_wr_l/hb_cs_l/hb_size[1:0]/busy_l/mode_set_l`（busy_l 低=忙，主机须保持请求） | 关键 |
| SDC-DRQ-IF-002 | TB 反门：DUT 内部模式寄存器与刷新调度计数器提供层次观察路径（`u_dut.*`，交付文档声明）供 TB 核对；存储阵列在 TB 器件模型侧实现 | 重要 |

## 6. 验证需求

| 编号 | 需求 | 级别 |
|---|---|---|
| SDC-DRQ-TST-001 | 自检 TB 内建**独立 SDRAM 器件行为模型**（按附录 A.1/A.2/A.3/A.7 完整实现：命令译码/行激活与列采样/CL2 读取/DQM 掩蔽/刷新间隔监视——两次刷新间隔 >2×781 周期置 REFRESH_VIOL=1）+ **独立软件参考存储阵列**（期望值不取自 DUT）+ 主机总线功能模型 | 关键 |
| SDC-DRQ-TST-002 | 必测场景：(a) 复位与初始化序列逐命令核验（等待窗/PC ALL/≥2×REF/MRS 顺序与模式字逐位）；(b) 8/16/32 位写读全组合含 lane 语义（A[1:0]×4、A[1]×2）；(c) 四 bank 全覆盖与跨 bank 交替访问；(d) 地址空间边界抽样（行 0/1/2047、列 0/1/255、bank×行×列最小覆盖集）；(e) 读延迟实测（SDC_RLAT）；(f) 刷新纪律观察（≥2ms 仿真时间窗内 REFRESH_VIOL=0）；(g) 刷新与访问仲裁（连续访问流中刷新照常插入、busy 行为正确）；(h) 模式寄存器装载（mode_set_l 写 → 器件模型收到的模式字逐位比对）；(i) 数据完整性（伪随机图案 ≥4096 位置写后读回全比对）；(j) **混合吞吐（PERF-003 验收）**：写读交替 ≥1024 次访问统计 SDC_MBPS；(k) 判线行 `SDC_RLAT`/`SDC_MBPS`/`REFRESH_VIOL` 进 stdout，digest 独立判定 | 关键 |
| SDC-DRQ-TST-003 | 每条需求规定验证方法并双向可追溯；**终局报告附 DRQ→证据覆盖矩阵**（无矩阵不判收官） | 关键 |
