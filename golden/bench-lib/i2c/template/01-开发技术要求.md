## 1. 范围

### 1.1 标识

- 项目标识：I2C-CTL（Synthia 基准库盲测 T2）
- 产品名称：I2C 主控制器可编程逻辑器件软件（PLDS），顶层标识 `i2c_master_top`
- 目标器件：Xilinx Kintex-7，型号 xc7k70tfbv676-1
- 适用阶段：G0～G4（需求、设计、RTL 基线）

### 1.2 系统概述

本 PLDS 实现一个两线制 I2C 总线主控制器（NXP UM10204 定义的主设备）：处理器侧经 8 位宽同步寄存器总线访问 5 组寄存器，发起起始/重复起始/停止条件、字节发送与接收；串行侧 SCL/SDA 为开漏驱动（只拉低或释放，外部上拉）。支持多主仲裁（含仲裁丢失检测与再试）、从机侧时钟拉伸等待、多主时钟线与同步、可编程 SCL 速率（标准模式 100 kHz 与快速模式 400 kHz）、命令完成与仲裁丢失中断。I2C 协议规范性定义（地址格式、应答位、时序参数、起始/停止条件电气定义）以 UM10204 为准，本文不复述。被寻址的从机工作模式（本核应答他主寻址）不在范围内。

### 1.3 基线

本文件为唯一需求输入基线；下游文档由本文件派生。任务要求以 `I2C-DRQ-*` 唯一标识。

## 3. 功能要求

### 3.1 寄存器空间（规范数据）

| 地址 | 寄存器 | 读写 | 位定义 |
|---|---|---|---|
| 0x00 | PRER_LO | RW | 预分频值低字节 |
| 0x01 | PRER_HI | RW | 预分频值高字节 |
| 0x02 | CTR | RW | bit7=EN（核使能），bit6=IEN（中断使能），其余保留读 0 |
| 0x03 | TXR | W | 发送字节（地址/数据） |
| 0x03 | RXR | R | 接收字节 |
| 0x04 | CR | W | bit7=STA，bit6=STO，bit5=RD，bit4=WR，bit3=ACK，bit0=IACK |
| 0x04 | SR | R | bit7=RXACK，bit6=BUSY，bit5=AL，bit1=TIP，bit0=IF，其余读 0 |

未定义地址（0x05～0x07）读回 0x00，写忽略。复位默认值：PRER=0xFFFF，CTR=0x00，状态位全 0。

| 编号 | 要求 | 关键度 |
|---|---|---|
| I2C-DRQ-FUN-001 | 寄存器读写经处理器侧总线单周期完成（零等待）；上表位定义、读写属性与复位默认值逐项实现。 | 关键 |
| I2C-DRQ-FUN-002 | 使能门控：EN=0 期间核不驱动 SCL/SDA（呈释放态），命令寄存器写入不启动任何总线操作；EN 置 1 后按新命令工作。 | 关键 |
| I2C-DRQ-FUN-003 | SCL 速率编程：f_scl = f_clk / (5 × (PRER+1))，要求 PRER ≥ 1；标准模式 100 kHz 与快速模式 400 kHz 均须经 PRER 配置可达（f_clk=100 MHz 时 PRER=199 / 49）。 | 关键 |
| I2C-DRQ-FUN-004 | 起始条件：STA 命令按 UM10204 起始条件时序（SCL 高时 SDA 下落）驱动；总线已占用时为重复起始（不先发停止）；数据相位中途收到 STA 命令同样按重复起始处理。 | 关键 |
| I2C-DRQ-FUN-005 | 停止条件：STO 命令按 UM10204 停止条件时序（SCL 高时 SDA 上跳）驱动；STOP 完成后 BUSY 清零。 | 关键 |
| I2C-DRQ-FUN-006 | 字节写：TXR 装载 + WR 命令 → SCL 低电平期移出 8 位（MSB 先行）、SCL 高电平期稳定，第 9 位释放 SDA 采样从机应答。命令完成后 SR.RXACK = 采样到的应答位电平（0=收到 ACK，1=NACK）。 | 关键 |
| I2C-DRQ-FUN-007 | 字节读：RD 命令 → SCL 高电平期逐位采样 8 位进 RXR（MSB 先行）；第 9 位按 CR.ACK 驱动：0=发送 ACK（拉低 SDA），1=发送 NACK（释放 SDA 为高）。 | 关键 |
| I2C-DRQ-FUN-008 | 命令握手：命令执行期间 SR.TIP=1；完成时 TIP 回落、IF 置位；CR 中 STA/STO/RD/WR/ACK 位完成后自动清零，IACK 写 1 清 IF。 | 关键 |
| I2C-DRQ-FUN-009 | 仲裁丢失：多主环境下本主发送 1 而 SDA 实际电平为 0 时判负——立即停止驱动 SDA、SR.AL 置位、IF 置位、进行中命令作废；AL 保持到下一次 STA 命令清除。本主不主动干扰胜者的后续传输。 | 关键 |
| I2C-DRQ-FUN-010 | 时钟拉伸：他设备（从机或他主）拉低 SCL 期间，主控暂停位时钟推进，待其释放后继续；拉伸等待期间与恢复后不得产生宽度不足的 SCL 脉冲。 | 关键 |
| I2C-DRQ-FUN-011 | 多主时钟同步：SCL 线与语义——他主先行拉低 SCL 时，本主低电平计时与之对齐（重置低电平计数）。 | 重要 |
| I2C-DRQ-FUN-012 | 总线忙检测：检测到起始条件（含他主生成）BUSY=1；检测到停止条件（含他主生成）后 BUSY=0。 | 重要 |
| I2C-DRQ-FUN-013 | 中断：命令完成与仲裁丢失置 IF；IEN=1 时 irq 输出电平跟随 IF，IEN=0 时 irq 恒 0；IACK 写 1 清 IF。 | 重要 |
| I2C-DRQ-FUN-014 | 输入抗扰：SCL/SDA 输入经毛刺滤波——显著短于四分之一 SCL 位周期的输入毛刺不得被识别为有效电平翻转、起始或停止条件。 | 重要 |
| I2C-DRQ-FUN-015 | 复位行为：复位释放后确定空闲态——不驱动总线、不悬挂中断、命令全部作废，寄存器恢复默认值。 | 关键 |

## 9. 测试要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| I2C-DRQ-TST-001 | 自检 TB 以寄存器访问任务模拟处理器侧驱动 DUT，串行侧挂从机行为模型（可编程应答/预载数据/可注入拉伸与毛刺）与竞争主控模型（可注入并行传输）；期望值由 TB 内建独立参考行为产生，不得取自 DUT。失败 `$fatal` 并打印场景号、期望与实际；全过打印 PASS。 | 关键 |
| I2C-DRQ-TST-002 | 必测场景：(a) 复位默认值与空闲不驱动；(b) 标准写事务 START+从地址+W+≥2 数据字节+STOP，从机逐位比对且回 ACK，RXACK=0；(c) 读事务 START+从地址+R+≥2 字节（末字节 NACK）+STOP，数据与模型预载一致；(d) 组合事务（写寄存器指针后重复起始读回）；(e) 从机 NACK 注入，RXACK=1 且后续事务不受污染；(f) SCL 频率实测（PRER=199 与 49，偏差 ≤10%）；(g) 从机时钟拉伸注入，传输正确完成且无短 SCL 脉冲；(h) 仲裁丢失注入（竞争主控发更低位值），AL 置位、本核停驱、IF 置位，重试事务成功；(i) BUSY 语义（START 后 1、STOP 后 0）；(j) 中断链路（IEN 门控、IACK 清除）；(k) 输入毛刺注入不影响在途传输；(l) ≥2 个事务背靠背连续执行。 | 关键 |
| I2C-DRQ-TST-003 | 每条需求规定验证方法并双向可追溯。 | 关键 |

## 12. 注释

本文档为 Synthia 基准库盲测基准（T2：标准压力）。协议语义以 NXP UM10204 为准，位极性约定（CR.ACK=1→NACK、SR.RXACK=0→收到 ACK）与公开规范及参考行为双源核对；本文不复述实现结构（模块划分、状态机形态、滤波器结构均属实现自由）。不作为真实装备交付文档。
