## 1. 范围

### 1.1 标识

- 项目标识：CPU-RV32I（Synthia 基准库盲测 T2）
- 产品名称：RV32I 微处理器核可编程逻辑器件软件（PLDS），顶层标识 `cpu_top`
- 目标器件：Xilinx Kintex-7，型号 xc7k70tfbv676-1
- 适用阶段：G0～G4（需求、设计、RTL 基线）

### 1.2 系统概述

本 PLDS 实现一个 32 位 RISC-V 整数微处理器核（RV32I 基础指令集，40 条指令，见附录 A 编码表）：经一个简单同步存储总线对外取指与访存；复位后从地址 0x0000_0000 取指执行；指令语义（寄存器模型、寻址模式、分支与跳转、自陷指令行为）以 RISC-V Non-Privileged ISA 手册为准，本文不复述。压缩指令（C）、乘除（M）、CSR/中断/计数器指令、MMU/特权级不在范围内。

### 1.3 基线

本文件为唯一需求输入基线（含附录 A 规范数据）；下游文档由本文件派生。任务要求以 `CPU-DRQ-*` 唯一标识。

## 3. 功能要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| CPU-DRQ-FUN-001 | 指令集：完整实现附录 A 所列 RV32I 40 条指令，语义与 RVISA 逐条一致（含符号/无符号比较、算术右移、位扫描 immediates 的符号扩展、JAL/JALR 链接、FENCE 作为空操作、ECALL/EBREAK 引发自陷）。 | 关键 |
| CPU-DRQ-FUN-002 | 寄存器模型：32 个 32 位通用寄存器 x0..x31；x0 恒 0（写忽略）；复位后全部寄存器为确定值 0x0000_0000。 | 关键 |
| CPU-DRQ-FUN-003 | 存储总线（native 协议）：`mem_valid` 拉高发起一次传输并保持至 `mem_ready` 拉高的那一拍；`mem_wstrb` 按字节写使能（读=0000、字=1111、半字=1100/0011、单字节 4 选 1）；`mem_rdata` 仅在 `mem_valid & mem_ready` 拍需要有效；`mem_instr` 指示取指访问。 | 关键 |
| CPU-DRQ-FUN-004 | 取指与执行：复位释放后从 PROGADDR_RESET=0x0000_0000 取指；指令地址非对齐（非 4 字节对齐跳转目标）按自陷处理（trap 输出有效并停机）。 | 关键 |
| CPU-DRQ-FUN-005 | 访存语义：LB/LH/LBU/LHU/LW/SB/SH/SW 的地址计算、字节序（小端）、部分字访问的 wstrb 映射与符号扩展逐项正确；非对齐 load/store 触发自陷。 | 关键 |
| CPU-DRQ-FUN-006 | 分支与跳转：全部 6 条条件分支的比较语义（含 BLTU/BGEU）、JAL/JALR 目标计算与返回地址（当前指令 +4）、跳转目标对齐检查。 | 关键 |
| CPU-DRQ-FUN-007 | 自陷可观测：ECALL/EBREAK/非法指令/总线错误/非对齐地址任一发生时 `trap` 输出置位并停止取指（停机态确定，不复位不恢复）。 | 关键 |
| CPU-DRQ-FUN-008 | 自修改代码：store 写入后紧接取指同地址时取到新数据（无陈旧取指缓存假设）。 | 重要 |
| CPU-DRQ-FUN-009 | 复位：低有效同步复位 `rstn`；复位释放后首拍即发起取指；复位期间总线无有效请求。 | 关键 |

## 4. 性能要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| CPU-DRQ-PERF-001 | 系统时钟 100 MHz，单时钟域；fmax 综合后 ≥ 100 MHz（WNS ≥ 0）。 | 关键 |
| CPU-DRQ-PERF-002 | 平均 CPI 不作验收硬指标（实现自由：单周期/多周期/微码皆可），但单条指令最坏周期数 ≤ 40（防呆界）。 | 重要 |
| CPU-DRQ-PERF-003 | 资源预算：LUT ≤ 8000，FF ≤ 4000，BRAM ≤ 16（寄存器堆/缓存自由），DSP=0。 | 重要 |

## 5. 接口要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| CPU-DRQ-IF-001 | 信号集合：`clk`、同步低有效 `rstn`、`mem_valid`、`mem_ready`、`mem_instr`、`mem_addr[31:0]`、`mem_wdata[31:0]`、`mem_wstrb[3:0]`、`mem_rdata[31:0]`、`trap`。 | 关键 |
| CPU-DRQ-IF-002 | `mem_ready` 允许组合直连恒 1（单周期存储）也允许延迟应答（TB 注入等待拍）；两种形态下功能等价。 | 关键 |
| CPU-DRQ-IF-003 | 顶层 I/O ≤ 32；引脚/电平由板级约束定义，属未决板级项。 | 关键 |

## 8. 安全可靠性要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| CPU-DRQ-REL-001 | 单时钟域；无未初始化状态（复位后寄存器堆/内部状态确定）。 | 关键 |
| CPU-DRQ-REL-002 | 总线死锁防护：`mem_ready` 长期不响应时核停在等待态（`mem_valid` 保持），不得产生额外总线副作用。 | 重要 |

## 9. 测试要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| CPU-DRQ-TST-001 | 自检 TB：挂同步存储模型（`$readmemh` 预载手写指令字，不依赖交叉工具链），经总线监视事务；判卷口约定：程序向魔数地址 0x2000_0000 写入 0x075BCD15 表示全部通过，`trap` 前检测；期望值由 TB 内建参考（手写指令字的已知语义结果）产生，不得取自 DUT。失败 `$fatal` 打印用例号、期望与实际；全过打印 PASS。 | 关键 |
| CPU-DRQ-TST-002 | 必测用例：(a) 复位确定性与首条取指地址；(b) 40 条指令每条 ≥2 个取值用例（含边界立即数 ±2048/±1、x0 写忽略、SRA 负数、SLTU/BLTU 无符号边界 0x8000_0000、JALR 对齐）；(c) load/store 全型 + 小端字节序 + 符号扩展；(d) 自修改代码（store 后取指同址）；(e) 非对齐跳转/访存 → trap；(f) 非法指令编码 → trap；(g) ECALL/EBREAK → trap；(h) 存储延迟注入（mem_ready 延迟 1-3 拍）功能不变；(i) 魔数口判卷链路。 | 关键 |
| CPU-DRQ-TST-003 | 每条需求规定验证方法并双向可追溯。 | 关键 |

## 12. 注释

本文档为 Synthia 基准库盲测基准（T2：标准压力，CPU 类代表，与寄存器接口类分开对比）。指令语义以 RISC-V ISA 手册为准；指令编码表属规范数据（附录 A，随输入包提供，防止记忆转录错误——DES 常量红线同源）；总线协议/复位行为/寄存器确定性属接口契约；本文不复述实现结构（流水级数、译码方式、参数矩阵均属实现自由）。不作为真实装备交付文档。
