## 1. 指令编码总表（40 条）

### 1.1 U 型（opcode[6:0]）

| 指令 | opcode | 说明 |
|---|---|---|
| LUI | 0110111 | rd = imm[31:12] << 12 |
| AUIPC | 0010111 | rd = pc + (imm[31:12] << 12) |

### 1.2 J 型

| 指令 | opcode | 说明 |
|---|---|---|
| JAL | 1101111 | rd=pc+4；pc += imm[20|10:1|11|19:12] 符号扩展 |

### 1.3 分支 B 型（opcode=1100011）

|---|---|
| BEQ | 000 |
| BNE | 001 |
| BLT | 100 |
| BGE | 101 |

| BGEU | 111 |

imm = imm[12|10:5|4:1|11] 符号扩展（×2）。

## 2. 判卷口约定（随附录一并声明）

- 魔数地址 0x2000_0000 写入 0x075B_CD15 = 全部用例通过
- `trap` 置位 = 自陷（ECALL/EBREAK/非法指令/总线错误/非对齐）
