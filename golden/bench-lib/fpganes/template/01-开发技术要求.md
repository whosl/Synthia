# NES PPU（2C02）渲染子系统 — 开发技术要求

- 文档编号：NES-PPU-REQ；版本 1.0（2026-10-14）
- 梯队：T3（收敛极限档）；出题卡：bench-lib/fpganes（子题按本卡 §1 裁剪：**仅 PPU**——6502/APU/卡带映射器不在范围）
- **统一器件：xc7k160tffg676-1（Kintex-7 160T，speed -1）**
- 规范基准：NESdev Wiki（nesdev.org）PPU 文档（公开权威）。本文不复述渲染管线的数学语义，只引用页面名与行为要求；数据类常量（寄存器位定义/内存映射/时序表）见附录 `std/nes-ppu-constants.md`。**附录与 NESdev 出入按阻塞上报，不自行勘误**（转录保险丝：TB 场景全覆盖 + 黄金侧四步暴露）
- 本文独立成篇：不引用任何参考实现的结构、命名或文件组织

## 1. 任务概述

实现 **NES PPU 渲染子系统**的可综合 RTL：CPU 侧寄存器接口（$2000-$2007 协议）、背景渲染（含滚动 loopy v/t 寄存器）、精灵渲染（8×8、每行 8 精灵求值、优先级/翻转）、调色板、NMI 帧同步、NTSC 时序（341×262 点阵）。对外接口为**像素流**（每 PPU 时钟一像素）+ VRAM（图案表/命名表经外部总线，片内集成 2KB 命名表镜像 + 32B 调色板 + 256B OAM）。

范围外（明确不做）：6502 CPU、APU、卡带映射器（mapper）、8×16 精灵模式（OQ-002）、PAL 时序、强调/emphasis 位、OAM DMA（CPU 侧）、渲染中（有效画面期内）动态改寄存器（见 REL-002）、灰度外的色彩处理（color 输出 6 位索引即止，不做 RGB）。

## 2. 术语

| 术语 | 含义 |
|---|---|
| 点/周期（dot） | PPU 基本时间单位；341 点×262 扫描线=1 帧 |
| 有效画面 | 扫描线 0-239、点 0-255（x=点号，256×240 可见像素） |
| 后沿（VBlank） | 扫描线 241 起；NMI 触发窗 |
| 预渲染行 | 扫描线 261；v/t 重装与奇偶帧跳点 |
| loopy v/t | 15 位滚动寄存器对（当前/临时），NESdev "PPU scrolling" 页 |
| 精灵 0 命中 | 精灵 0 不透明像素与背景不透明像素重叠，置 $2002 bit6 |

## 3. 功能需求

| 编号 | 需求 | 级别 |
|---|---|---|
| PPU-DRQ-FUN-001 | **寄存器协议**：$2000 PPUCTRL/$2001 PPUMASK/$2002 PPUSTATUS/$2003 OAMADDR/$2004 OAMDATA/$2005 PPUSCROLL/$2006 PPUADDR/$2007 PPUDATA 全实现，读写语义/副作用/读清除按附录 A.2（含 $2002 读清 VBlank、$2005/$2006 双写锁存、$2007 读写自增、$2004 读写 OAM） | 关键 |
| PPU-DRQ-FUN-002 | **NTSC 时序**：341 点×262 线帧循环；VBlank 置位在 241:1，NMI 在 VBlank 置位且 NMI 使能时发出；预渲染行 261 清 VBlank 与精灵 0 命中；奇偶帧跳点（预渲染行末点在奇帧且渲染使能时跳过）按 NESdev "PPU frame timing" | 关键 |
| PPU-DRQ-FUN-003 | **背景渲染管线**：图案/属性字节取数节拍（8 点循环，含 2 点预取）、平铺索引/属性位选择、fine X 滚动、平铺水平/垂直翻转由属性位控制（背景无翻转，仅精灵有——背景按位取属性 2bit 选调色板）、 shifts 与 fine X 多路；命名表/图案表基址由 PPUCTRL 选择 | 关键 |
| PPU-DRQ-FUN-004 | **loopy 滚动寄存器**：v/t 语义按 NESdev "PPU scrolling"——$2005/$2006 写 t 的各字段、有效渲染期 v 的 coarse X/Y 自增与 X 回绕进位命名表、行末 coarse X 重装 t、y 回绕进位 fine Y、预渲染行 y 重装（条件 280-304 按附录 A.4 简化口径）；$2007 访问读写 v 并按 PPUCTRL bit2 增量 1/32 | 关键 |
| PPU-DRQ-FUN-005 | **精灵渲染**：OAM 256B；每行精灵求值（y 在范围内的前 8 个，溢出置 $2002 bit5——本子题只置位不绘第 9 个）；8 个次级精灵槽（属性含调色板/优先级/水平/垂直翻转）；移位输出与 8×1 图案；背景优先级仲裁按 NESdev "PPU OAM"（精灵 0 与背景优先规则） | 关键 |
| PPU-DRQ-FUN-006 | **精灵 0 命中**：精灵 0 不透明像素与背景不透明像素在有效画面重叠时置位（x=255 不触发、x<8 且左掩关不触发——按附录 A.5 口径） | 关键 |
| PPU-DRQ-FUN-007 | **调色板与输出**：32B 调色板（背景 4×4 + 精灵 4×4 + 镜像）；输出 6 位颜色索引（$2001 灰度位有效时 AND 0x30）；左列 8 像素掩码（背景/精灵独立掩码）按 $2001 | 关键 |
| PPU-DRQ-FUN-008 | **片内存储**：命名表 2KB（镜像模式固定**水平镜像**，OQ-003）、调色板 32B、OAM 256B；图案表经外部 VRAM 总线（4KB 窗 ×2 由 PPUCTRL 基址选择）；TB 反门装载 | 关键 |
| PPU-DRQ-FUN-009 | **渲染开关语义**：$2001 bit3/bit4 开背景/精灵；关渲染时输出背景色（调色板 $3F00）且 v 不自增；**寄存器只在 VBlank 期写**（REL-002 简化），有效画面期写属未定义（TB 不测） | 关键 |

## 4. 性能需求

| 编号 | 需求 | 级别 |
|---|---|---|
| PPU-DRQ-PERF-001 | 系统时钟 50 MHz 单时钟域；PPU 内部经时钟使能降为 1 点/4 系统时钟（等效 5.37 MHz dot rate，NTSC 近似——绝对频率不要求精确 NTSC，帧内相对时序必须精确） | 关键 |
| PPU-DRQ-PERF-002 | **帧渲染吞吐**：一帧 89,342 点（341×262）内完成完整渲染——`FRAME_DOTS` 打印=89,342（含奇偶帧跳点容差 89,341）且 `PIXEL_ERR=0`。测量口径见 TST-002(k) | 关键 |
| PPU-DRQ-PERF-003 | 时序收敛：50MHz 约束 WNS ≥ 0（XDC clock-only，NSTD-1/UCIO-1 豁免） | 关键 |
| PPU-DRQ-PERF-004 | 资源预算：LUT ≤ 8000、FF ≤ 6000、BRAM ≤ 12 tile、DSP ≤ 4 | 重要 |

## 5. 接口需求

| 编号 | 需求 | 级别 |
|---|---|---|
| PPU-DRQ-IF-001 | 顶层 `nes_ppu_top`：`clk/rst`、CPU 侧 `cpu_ce, cpu_addr[2:0], cpu_din[7:0], cpu_dout[7:0], cpu_rd, cpu_wr, nmi`、像素流 `pix_ce, color[5:0], pix_x[7:0], pix_y[7:0], pix_valid`（pix_x/y 为帧内坐标，供 TB 采样）、VRAM 侧 `vram_addr[13:0], vram_dout[7:0]`（读入），`vram_rd`（读使能，TB 组合/1 拍供数） | 关键 |
| PPU-DRQ-IF-002 | TB 反门：`u_dut.u_nt.mem[]`（命名表）、`u_dut.u_pal.mem[]`、`u_dut.u_oam.mem[]`（或等价层次路径，交付文档声明）；VRAM（图案表）由 TB 侧实现并按 `vram_addr` 供数 | 重要 |
| PPU-DRQ-IF-003 | `pix_valid` 仅在有效画面（y 0-239、x 1-256）为高；其余点输出背景色但 valid=0 | 关键 |

## 6. 验证需求

| 编号 | 需求 | 级别 |
|---|---|---|
| PPU-DRQ-TST-001 | 自检 TB 内建**独立软件渲染参考模型**（按附录 A + NESdev 语义的逐像素帧渲染器，期望帧不取自 DUT）+ CPU 侧总线 BFM（VBlank 期写寄存器/读状态） | 关键 |
| PPU-DRQ-TST-002 | 必测场景：(a) 复位确定性与初始状态；(b) 寄存器协议逐条（双写锁存/读清除/自增/OAM 读写）；(c) 背景单平铺/多平铺全帧逐像素；(d) 滚动（fine X/coarse X 回绕/Y 进位命名表/预渲染重装）；(e) 属性位四调色板；(f) 精灵基础（单/多/行边界 y 判定）；(g) 精灵翻转（H/V）；(h) 精灵优先级（前景/背景）与 8 上限+溢出位；(i) 精灵 0 命中（命中/不命中/掩码边缘）；(j) 掩码/灰度/渲染开关；(k) **帧渲染吞吐（PERF-002 验收）**：满配置帧（背景+满屏精灵+滚动非零）跑完整帧，`FRAME_DOTS`/`PIXEL_ERR`/`SPRITE0_DOT` 三行进 stdout——digest 判 PIXEL_ERR≠0 或 FRAME_DOTS∉{89341,89342} 即 FAIL | 关键 |
| PPU-DRQ-TST-003 | 每条需求规定验证方法并双向可追溯；**终局报告附 DRQ→证据覆盖矩阵**（无矩阵不判收官——H34 教训固化） | 关键 |

## 7. 环境与约束

| 编号 | 需求 | 级别 |
|---|---|---|
| PPU-DRQ-ENV-001 | 器件 xc7k160tffg676-1；Vivado 2021.1 | 关键 |
| PPU-DRQ-ENV-002 | DRC 豁免：NSTD-1/UCIO-1（clock-only XDC） | 重要 |
| PPU-DRQ-REL-001 | 单时钟域 50MHz；时钟使能降频，无 CDC | 关键 |
| PPU-DRQ-REL-002 | **寄存器写简化**：TB 全部寄存器操作限定 VBlank 期（含 $2007 VRAM 预载走 TB 反门不走 CPU 口）；渲染期动态改寄存器不在验收面（如实声明为简化边界） | 关键 |
| PPU-DRQ-DEV-001 | Verilog-2001 可综合子集；片内存储用可推断风格（BRAM/分布式皆可） | 重要 |
| PPU-DRQ-DEV-002 | 微架构选型（取数节拍/移位器组织/精灵求值流水）在交付文档记录 | 重要 |
| PPU-DRQ-DLV-001 | 交付：RTL 全集、top.xdc、自检 TB（含软件渲染模型）、实现说明、**DRQ 覆盖矩阵** | 关键 |
| PPU-DRQ-DLV-002 | 四步验证链全绿；数值实读；性能数字的**度量面本身**（计数器门控/打印时机）在报告中说明（黄金侧 No.25 教训） | 关键 |

## 8. 开放问题

| 编号 | 问题 | 裁定 |
|---|---|---|
| NES-OQ-001 | 强调位（emphasis） | 不做（视频输出级，输出为止于 6bit 索引） |
| NES-OQ-002 | 8×16 精灵模式 | 不做（PPUCTRL bit5 读回允许写、行为不定义，TB 不测） |
| NES-OQ-003 | 命名表镜像模式 | 固定水平镜像（垂直/四屏不做；PPUCTRL bit0/bit1 仍控制基址选择） |
| NES-OQ-004 | 奇偶帧跳点 | 做（NTSC 特征，纳入 FUN-002） |
