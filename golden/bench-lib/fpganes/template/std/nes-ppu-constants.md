# NES PPU 常量附录（渲染子系统子题）

- 文档编号：NES-PPU-CONST；版本 1.0（2026-10-14）
- 与《01-开发技术要求》同等约束力。**权威性：一切以 NESdev Wiki（nesdev.org）PPU 页面为准；出入按阻塞上报。** 保险丝：TST 场景全覆盖 + 黄金侧四步暴露
- 期望帧一律由 TB 软件渲染模型生成，本文不预置帧数据

## A.1 时序常量（NESdev "PPU rendering" / "PPU frame timing"）

| 项 | 值 |
|---|---|
| 每线点数 | 341（点 0-340） |
| 帧线数 | 262（线 0-261） |
| 有效画面 | 线 0-239，点 1-256（x 坐标 = 点-1） |
| 后置扫描线（post-render） | 线 240-260（空闲） |
| VBlank 置位 | 线 241 点 1 |
| VBlank 清除 | 预渲染线 261 点 1 |
| NMI | VBlank 置位时若 PPUCTRL bit7=1 则 nmi 拉低（有效）至读 $2002 或 VBlank 结束 |
| 预渲染行 | 线 261；y 重装窗点 280-304；**奇偶跳点：奇数帧且渲染使能（bg 或精灵任一开）时预渲染行点 340 跳过**（本子题：帧计数从复位后第 1 帧为奇） |
| 背景取数节拍 | 有效画面线（0-239）与预渲染线：点 1-256 与 321-336 每 8 点一平铺周期（2 点名称表字节→2 点属性→2 点图案低/高，NESdev 节拍表）；本子题**只要求结果正确与 FRAME_DOTS 正确，取数节拍微观等价不作验收**（DEV-002 记录选型即可） |

## A.2 寄存器（$2000-$2007；NESdev "PPU registers"）

| 口 | 名称 | 位定义 |
|---|---|---|
| $2000 W | PPUCTRL | bit7 NMI 使能；bit6 PPU 主/从（不做，读写回）；bit5 8×16 精灵（不做，读回存写值）；bit4 背景图案表基址（0=$0000/1=$1000）；bit3 精灵图案表基址（8×8 用）；bit2 $2007 增量（0=+1/1=+32）；bit1:0 命名表基址选择（配合 A.3 镜像） |
| $2001 W | PPUMASK | bit5 灰度（AND 0x30）；bit4 背景左 8 掩码；bit3 精灵左 8 掩码；bit3:2 写读回；bit1 精灵使能；bit0 背景使能 |
| $2002 R | PPUSTATUS | bit7 VBlank（读清除，含 NMI 复位）；bit6 精灵 0 命中（预渲染线 261 点 1 清）；bit5 精灵溢出（清同上）；bit4:0 开放总线（本子题读 0）；**读此口清 VBlank 与 NMI** |
| $2003 W | OAMADDR | OAM 写指针（本子题 OAMADDR 只作 $2004 访问指针；求值期重置语义不做——见 A.5 简化） |
| $2004 R/W | OAMDATA | 读=OAM[OAMADDR]（无延迟缓冲——简化：直读）；写=OAM[OAMADDR++]（本子题 OAM 预载走 TB 反门，此口定向场景仍测读写语义） |
| $2005 W×2 | PPUSCROLL | 第 1 写 t.bit4:0=fine X；第 2 写 t.bit14:12=fine Y、t.bit9:5=coarse Y；**双写锁存 toggle 与 $2006 共用** |
| $2006 W×2 | PPUADDR | 第 1 写 t.bit13:8（高 6 位）；第 2 写 t.bit7:0 且 **v=t**；toggle 共用；**读 $2002 复位 toggle** |
| $2007 R/W | PPUDATA | 读=VRAM[v]（命名表/调色板窗内读片内；图案表走 vram 总线——**简化：本子题 $2007 读图案表返回 0**，图案表只经渲染取数用，VRAM 预载全走 TB 反门/侧供给）；写同理片内窗内落片内；访问后 v += (PPUCTRL.bit2?32:1)；调色板窗读不增 v 之外的镜像副作用不做 |

**$2007 调色板窗**：v 落 $3F00-$3FFF 时读写直通调色板（$3F10/$14/18/1C 镜像自 $3F00/04/08/0C——写 $3F1x 落 $3F0x，读同）。

## A.3 内存映射（NESdev "PPU memory map" + 本子题镜像裁定）

| 区间 | 内容 | 本子题 |
|---|---|---|
| $0000-$1FFF | 图案表（卡带 CHR） | **外部 vram 总线**（TB 侧 4KB×2 供数，PPUCTRL bit4/bit3 选基址） |
| $2000-$2FFF | 命名表 | 片内 2KB **水平镜像**：$2000/$2400→物理 A，$2800/$2C00→物理 B；PPUCTRL bit1:0 基址经镜像后选择 |
| $3F00-$3FFF | 调色板 | 片内 32B（含 A.2 镜像规则）；$3F04/$08/$0C（与 $3F10/14/18/1C）存背景色语义（$3F00 为背景色） |

命名表字节：bit9:0=平铺号（低 8 位查图案表、bit9:8 选 256B 窗内 +基址）；属性字节：每 2bit 管 32×32 像素区（bit1:0=左上区…按 NESdev "PPU attribute table" 四象限，附录表照抄——bit7:6 左上、bit5:4 右上、bit3:2 左下、bit1:0 右下选调色板 0-3）。

## A.4 滚动寄存器 loopy v/t（NESdev "PPU scrolling"；15 位）

```
v/t: bit14:12 fine Y | bit11 命名表 X | bit10 命名表 Y | bit9:5 coarse Y | bit4:0 coarse X
```

- $2005 第 2 写 / $2006 第 1 写同时写 t 的对应段（$2006 第 1 写还清 t.bit14）
- 有效渲染期（背景使能且线 0-239 或 261）：每点 coarse X 自增；X 回绕（bit4:0 从 31→0）时 bit11 翻转；点 256 y 自增（fine Y 溢出进 coarse Y，coarse Y=29 回绕到 0 且 bit10 翻转——**简化：垂直回绕按 NESdev 精确规则，含 29→0 特例**）；点 257 coarse X 重装 t.bit4:0/bit11；预渲染线点 280-304 y 段（bit14:10:9:5）重装 t
- 渲染关（背景使能=0）时 v 不自增（FUN-009）

## A.5 精灵（NESdev "PPU OAM" + 简化口径）

- OAM 256B：64 精灵 × 4B（[y, tile, attr, x]）；attr：bit7:6 无用（读回）、bit5 优先级（1=背景后）、bit4 bit0=调色板 0-3、bit1:0=调色板；**attr 位序：bit7 V 翻转、bit6 H 翻转、bit5 优先级、bit4:2 无用、bit1:0 调色板**（位序以 NESdev OAM 页为准——bit7=垂直翻转、bit6=水平翻转、bit5=优先级、bit1:0=调色板；bit4:2 读回存写值不使用）
- 行求值：y 判定 = 行号落在 [sprite_y, sprite_y+8)（y 为顶行号-1 语义即 sprite_y+1 ≤ line < sprite_y+9——**以 NESdev "OAM 数据 y 是顶行-1" 口径**：显示行 L 上出现当 y+1 ≤ L ≤ y+8）；取前 8 个，第 9+ 置溢出位（本子题：只置位、不绘）；**OAMADDR 求值期重置不做**（简化：求值永远从 OAM[0] 扫全 64）
- 图案：8×8 tile 从 PPUCTRL bit3 基址取；每行 8 像素 2bit（位平面 0/1），H 翻转反序、V 翻转取 7-row
- 优先级仲裁（逐像素，从精灵 7→0 低到高覆盖，同列不透明精灵低编号覆盖高编号）：精灵像素不透明且（优先级=前景 或 背景像素透明）→ 输出精灵色；精灵 0 命中 = 精灵 0 不透明 且 背景不透明（同点）且 x≠255 且 左掩窗内规则（见 FUN-006）
- 左掩（$2001 bit3/bit4 关=掩）：x<8 时对应层输出透明（背景掩关→背景视为透明输出背景色；精灵掩关→精灵视为透明）

## A.6 输出颜色

- 6 位 color = 最终选中像素的调色板项低 6 位（灰度位 AND 0x30）；无像素（透明/掩掉/渲染关）= 调色板 $3F00 项
- 有效画面外（点 0、257-340、线 240-261）输出背景色但 pix_valid=0
