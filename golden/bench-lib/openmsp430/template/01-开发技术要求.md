# MSP430 兼容 16 位 CPU 核 — 开发技术要求

- 文档编号：MSP-CORE-REQ；版本 1.0（2026-10-12）
- 梯队：T3（收敛极限档）；出题卡：bench-lib/openmsp430（子题按本卡 §1 裁剪：**CPU 核本体**——参考树无核内 timer/uart，出题卡"外设子集"建议依实修正）
- **统一器件：xc7k160tffg676-1（Kintex-7 160T，speed -1）**
- 规范基准：TI MSP430x1xx Family User's Guide（SLAU049 系列，公开 PDF）。本文不复述 ISA 数学语义，只引用章节号与行为要求；数据类常量（操作码映射/CG 常量/状态位定义）见附录 `std/msp430-isa.md`。**附录与 TI 手册出入按阻塞上报，不自行勘误**（jpeg 附录 A.1 教训）
- 本文独立成篇：不引用任何参考实现的结构、命名或文件组织

## 1. 任务概述

实现一个 **MSP430 兼容的 16 位 RISC CPU 核**（正交寄存器组 R0-R15，冯·诺依曼统一 16 位地址空间，字对齐指令流），含核内必要部件（取指、译码、执行、寄存器堆、状态位、中断系统）与片上 RAM/SIM 孔径集成层。**外设（timer/uart/gpio 等）不在范围内**（参考实现为纯核，外设属 SoC 集成层）；调试模块（debug interface）不在范围；低功耗模式（LPM）不在范围（见 OQ-002）；MSP430X 扩展指令不在范围。

范围外：看门狗、NMI（可选实现）、BCS 时钟系统、DMA、硬件乘法器控制器外设（乘法用指令序列实现）、LPM0-4、调试接口、JTAG。

## 2. 术语

| 术语 | 含义 |
|---|---|
| 核心指令 | MSP430 的 27 条硬件指令（12 条双操作数 + 7 条单操作数 + 8 条跳转），见附录 A.2 |
| 模拟指令 | 汇编层的 24 条伪指令（NOP/POP/RLA 等），无独立硬件编码——测试程序只用核心编码 |
| CG | 常数发生器（R2=SR/CG1、R3=CG2 的寻址模式常量），见附录 A.3 |
| SIM 孔径 | 本考卷定义的仿真观测地址窗（0x0100-0x011F），非 MSP430 标准，见 IF-003 |

## 3. 功能需求

| 编号 | 需求 | 级别 |
|---|---|---|
| MSP-DRQ-FUN-001 | **27 条核心指令全实现**（MOV/ADDC/ADD/SUBC/SUB/CMP/DADD/BIT/BIC/BIS/XOR/AND；RRC/SWPB/RRA/SXT/PUSH/CALL/RETI；8 条条件跳转），字/字节（.w/.b）双宽度，置位语义（V/N/Z/C）按 SLAU049 §3.3 表逐条 | 关键 |
| MSP-DRQ-FUN-002 | **7 种寻址模式**（寄存器/变址 X(Rn)/间接 @Rn/间接自增 @Rn+/立即 #N/绝对 &/相对——含 CG 常量模式的全部 12 种组合语义）按 SLAU049 §3.2-§3.4；立即数与变址扩展字的取字次序按规范 | 关键 |
| MSP-DRQ-FUN-003 | **寄存器组**：R0=PC、R1=SP、R2=SR（仅低 9 位有效，写入掩蔽）、R3=CG2、R4-R15 通用；PUSH/CALL/RETI/中断对 SP 的次序与栈帧内容（PC/SR 双字压栈）按规范 | 关键 |
| MSP-DRQ-FUN-004 | **中断系统**：GIE（SR.3）控制的可屏蔽中断；≥2 条独立请求线（TB 驱动），向量表 0xFFE0-0xFFFE（偶地址对齐）；中断接受时机（指令边界）、压栈内容（PC+S R）、SR 清 GIE 入中断、RETI 全恢复按 SLAU049 §3.4.6；复位向量 0xFFFE 冷启动 | 关键 |
| MSP-DRQ-FUN-005 | **取指与执行流**：指令字对齐；扩展字（立即数/变址/跳转偏移）跟随指令字；未定义/非法编码按 NOP 处理不挂死（或按你定义的确定性行为并在文档声明） | 关键 |
| MSP-DRQ-FUN-006 | **访存一致性**：16 位统一地址空间，字访问偶地址对齐（奇地址字访问按你定义的确定性行为并声明）；字节访问高位补零/符号语义按指令类别 | 关键 |
| MSP-DRQ-FUN-007 | **片上 RAM**：≥16KB 单口 BRAM（参数化深度），统一存指令与数据；TB 经反门初始化（sim 专用），综合综合时不要求初始化 | 关键 |
| MSP-DRQ-FUN-008 | **SIM 孔径**：0x0100=SIMOUT（写：观测数据；读：返回 0）、0x0108=SIMHALT（写任意值=请求停机，写 0x1 停机、写 0x2 错误停机）、0x0110=SIMSTAT（只读，bit0=已停机标志）；孔径外 RAM 常规读写 | 关键 |

## 4. 性能需求

| 编号 | 需求 | 级别 |
|---|---|---|
| MSP-DRQ-PERF-001 | 系统时钟 **50 MHz 单时钟域** | 关键 |
| MSP-DRQ-PERF-002 | **基准程序吞吐**：附录 A.5 标准测试程序（含全指令覆盖的算术/逻辑/访存/分支/中断混合负载）跑至 SIMHALT(1)，**功能自检全过**（checksum 与内存终态比对）且 `CORE_CYCLES ≤ 400,000`。测量口径见 TST-002(k) | 关键 |
| MSP-DRQ-PERF-003 | 时序收敛：50MHz 约束下 WNS ≥ 0（XDC clock-only，NSTD-1/UCIO-1 豁免口径同前作） | 关键 |
| MSP-DRQ-PERF-004 | 资源预算：LUT ≤ 12000、FF ≤ 8000、BRAM ≤ 20 tile、DSP ≤ 8 | 重要 |

注：**不要求周期精确兼容**（不按 TI 手册的逐模式周期表执行）——功能按架构状态判定，性能按自测 CPI 判定。这是刻意的自由度：微架构（多周期/流水/前瞻）自选，对比报告以此为变量。

## 5. 接口需求

| 编号 | 需求 | 级别 |
|---|---|---|
| MSP-DRQ-IF-001 | 顶层 `msp_core_top`：`clk`、同步高有效 `rst`、`irq[1:0]`（中断请求，与时钟同步的电平请求）、RAM 与 SIM 孔径在核内集成（无外部存储端口） | 关键 |
| MSP-DRQ-IF-002 | TB 反门：`u_dut.u_ram.mem[]`（或等价层级路径，须在交付文档声明）用于程序装载与终态检查 | 重要 |
| MSP-DRQ-IF-003 | SIM 孔径行为见 FUN-008；停机后核冻结（PC 不再推进），TB 以 SIMSTAT.bit0 确认 | 关键 |

## 6. 验证需求

| 编号 | 需求 | 级别 |
|---|---|---|
| MSP-DRQ-TST-001 | 自检 TB 内建**独立 ISA 参考模型**（按附录 A.2-A.4 表驱动的行为级解释器，期望值不取自 DUT）；程序装载经反门、观测经反门+SIM 孔径双路 | 关键 |
| MSP-DRQ-TST-002 | 必测场景：(a) 复位确定性与向量冷启动；(b) 27 指令逐条定向（每条至少含 Rn/#N/&X(Rn) 三模式、.w/.b 双宽度、置位标志逐条查）；(c) CG 全 12 组合定向；(d) 寻址模式交叉（源×目的全 4×4 矩阵抽样 + @Rn+ 边界）；(e) CALL/PUSH/RETI 栈语义与 SP 边界；(f) 跳转全 8 条件×正负偏移×边界（-1/+1/极限）；(g) 中断：GIE 开关/请求时机（指令边界）/嵌套禁止（GIE 自清）/RETI 恢复/向量取数；(h) 非法编码不挂死；(i) 字/字节奇地址行为一致性；(j) 基准程序全量（checksum+内存终态+SIMOUT 序列）；**(k) 吞吐（PERF-002 验收）：(j) 程序计数周期并打印 `CORE_CYCLES <n>` 行进 stdout——digest 判定 n>400000 即 FAIL，功能自检失败亦 FAIL，不得以定向场景通过替代** | 关键 |
| MSP-DRQ-TST-003 | 每条需求规定验证方法并双向可追溯；终局报告附 DRQ→证据覆盖矩阵 | 关键 |
