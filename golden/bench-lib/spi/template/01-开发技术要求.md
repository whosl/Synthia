# SPI 主控制器 — 开发技术要求

- 文档编号：SPI-MST-REQ；版本 1.0（2026-10-20）
- 梯队：T4（再验证轮）；出题卡：bench-lib/spi
- **统一器件：xc7k160tffg676-1（Kintex-7 160T，speed -1）**
- 规范基准：Motorola/Freescale SPI 总线规范（公开）+ 器件时序公开文档。本文不复述 CPOL/CPHA 数学语义，只引用模式号与行为要求；数据类常量（寄存器位定义/地址映射/模式真值表）见附录 `std/spi-constants.md`。**附录与规范出入按阻塞上报，不自行勘误**（转录保险丝：复述关+黄金侧四步双暴露）
- 本文独立成篇：不引用任何参考实现的结构、命名或文件组织

## 1. 任务概述

实现一个 **SPI 主控制器**的可综合 RTL：寄存器接口（可配置分频/字符长/模式/片选）、四线主侧信号（SCK/MOSI/MISO/SS[7:0]）、全双工移位、四种 CPOL×CPHA 模式、中断与完成状态、LSB/MSB 可选。**从机拓扑不做**（主侧独占；MISO 为输入采样）。

范围外（明确不做）：SPI 从模式、多主仲裁、菊花链、三线（双向 MOSI/MISO 合并）、DMA、四线 Quad-SPI。

## 2. 术语

| 术语 | 含义 |
|---|---|
| CPOL | 时钟极性（空闲电平 0/1） |
| CPHA | 时钟相位（第一/第二边沿采样） |
| 模式 0-3 | CPOL×CPHA 组合 |
| ASS | 片选自动握手（每字符独立拉放）vs 持续保持（多字符同 SS） |
| 字符 | 一次移位传输的位串（1-128 位可编程） |

## 3. 功能需求

| 编号 | 需求 | 级别 |
|---|---|---|
| SPI-DRQ-FUN-001 | **寄存器接口**：DIVIDER（16 位时钟分频）/CTRL（控制+状态）/TX[3:0]（4 字发送缓冲，写触发）/RX[3:0]（4 字接收缓冲）/SS（8 位片选），地址映射与位定义按附录 A.2；读 RX 不清标志（清另有机制见 A.2） | 关键 |
| SPI-DRQ-FUN-002 | **四种边沿组合全支持**（勘误 E2：初版"四模式"中模式 2/3 需 CPOL 位，附录与实现均无此位，移出范围）：规范模式 0（TXN=1,RXN=0）与模式 1（TXN=0,RXN=1）+ 同沿组合 (0,0)（复位默认）与 (1,1)，各自采样/驱动边沿按附录 A.3 修正真值表；发送在驱动边沿更新 MOSI、接收在采样边沿锁存 MISO | 关键 |
| SPI-DRQ-FUN-003 | **可编程字符长 1-128 位**（CHAR_LEN+1）；移位逐位推进；MSB 先行默认、LSB 位可反转；不足 32 位的短字符对齐语义按附录 A.4 | 关键 |
| SPI-DRQ-FUN-004 | **分频器**：SCK = wb_clk / (2×(DIVIDER+1))；DIVIDER=0 时 SCK=wb_clk/2；16 位可编程 | 关键 |
| SPI-DRQ-FUN-005 | **片选语义**：8 位 SS 输出直接映射寄存器位；ASS=1 时每字符传输期间自动拉低选中线、字符间释放；ASS=0 时 SS 保持寄存器值跨字符（多字符突发） | 关键 |
| SPI-DRQ-FUN-006 | **全双工移位**：TX 缓冲在传输启动后逐位移出、MISO 同步逐位移入 RX 缓冲；传输完成 RX 就绪；TX 写入时若上一传输未完按 A.2 缓冲语义 | 关键 |
| SPI-DRQ-FUN-007 | **状态与中断**：CTRL 含传输进行（GO/忙）与接收就绪（Rx 完成标志）状态位；IE=1 时完成/就绪拉中断；忙标志读语义（读即动作或读即清除按附录 A.2 冻结口径） | 关键 |
| SPI-DRQ-FUN-008 | **复位**：同步高有效；全部寄存器/移位器/SS 释放（全高）恢复空闲 | 关键 |

## 4. 性能需求

| 编号 | 需求 | 级别 |
|---|---|---|
| SPI-DRQ-PERF-001 | 系统时钟 50 MHz 单时钟域 | 关键 |
| SPI-DRQ-PERF-002 | **最大 SCK 吞吐**：DIVIDER=0 时 SCK=25 MHz（wb_clk/2）；以 128 位最大字符连续传输测 `SPI_KBPS` ≥ 3000（3 MB/s 等效全双工）。测量口径见 TST-002(k) | 关键 |
| SPI-DRQ-PERF-003 | 时序收敛：50MHz WNS ≥ 0（clock-only XDC，NSTD-1/UCIO-1 豁免） | 关键 |
| SPI-DRQ-PERF-004 | 资源预算：LUT ≤ 4000、FF ≤ 3000、BRAM ≤ 8、DSP ≤ 4 | 重要 |

## 5. 接口需求

| 编号 | 需求 | 级别 |
|---|---|---|
| SPI-DRQ-IF-001 | 顶层 `spi_master_top`：`clk/rst`、总线侧 `bus_ce/bus_addr[4:0]/bus_din[31:0]/bus_dout[31:0]/bus_we/bus_int`（同步单拍或类 wishbone 握手，自定并在交付文档声明）、SPI 侧 `sck/mosi/miso/ss[7:0]` | 关键 |
| SPI-DRQ-IF-002 | TB 反门：`u_dut.u_tx*.mem` 或等价缓冲层次路径（交付文档声明）；MISO 由 TB 侧从机行为模型驱动 | 重要 |

## 6. 验证需求

| 编号 | 需求 | 级别 |
|---|---|---|
| SPI-DRQ-TST-001 | 自检 TB 内建**独立 SPI 从机行为模型**（按附录模式真值表驱动 MISO/采样 MOSI，期望值不取自 DUT）+ 独立参考模型（寄存器语义影子）；失败 `$fatal` 带场景/位偏移/期望实际 | 关键 |
| SPI-DRQ-TST-002 | 必测场景：(a) 复位确定性与 SS 释放；(b) 寄存器读写/位域/只读位；(c) 四模式各 8/16/32 位字符全双工逐位（含模式 3 边沿敏感）；(d) 短字符 2/5/7 位对齐（勘误 E7：1 位字符需 CHAR_LEN=0，参考口径下 0=128 位别名——1 位不可达，最小 2 位）；(e) LSB 反转；(f) 128 位长字符；(g) DIVIDER 扫描（0/1/最大）SCK 周期实测；(h) ASS 开/关的 SS 时序（每字符拉放 vs 保持突发）；(i) 中断开/关与完成标志；(j) TX 缓冲四字轮转与背压；(k) **吞吐（PERF-002 验收）**：DIVIDER=0 连续 128 位字符 ≥256 次传输，统计等效 KBPS，打印 `SPI_KBPS <n>` 行进 stdout——digest 判 n<3000 即 FAIL | 关键 |
| SPI-DRQ-TST-003 | 每条需求规定验证方法并双向可追溯；**终局报告附 DRQ→证据覆盖矩阵**（无矩阵不判收官） | 关键 |
