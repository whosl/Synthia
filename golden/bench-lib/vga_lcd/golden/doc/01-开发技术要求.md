## 1. 范围

### 1.1 标识

- 项目标识：VGA-CTL（Synthia 基准库盲测 T2）
- 产品名称：VGA/LCD 显示控制器可编程逻辑器件软件（PLDS），顶层标识 `vga_top`
- 目标器件：Xilinx Kintex-7，型号 xc7k70tfbv676-1
- 适用阶段：G0～G4（需求、设计、RTL 基线）

### 1.2 系统概述

本 PLDS 实现一个可编程视频显示控制器：处理器侧经 32 位宽同步寄存器总线配置控制器并读写显存；显存侧经只读突发取数接口按扫描顺序获取像素；视频侧输出行/场同步、消隐与像素数据流。支持每像素 8/16/24 位色深、双显存 bank（A/B）带垂直回扫期切换、可编程行场时序（同步宽度/门延迟/门宽度/总长度逐段编程）、行/场/换 bank/欠载中断。时序组织以 VESA CVT/GTF 术语（同步脉冲、前后沿、有效区、总长度）为准。CLUT 伪彩色模式、硬件光标、半平面 YCbCr 不在范围内。

### 1.3 基线

本文件为唯一需求输入基线；下游文档由本文件派生。任务要求以 `VGA-DRQ-*` 唯一标识。

## 3. 功能要求

### 3.1 寄存器空间（规范数据）

| 地址 | 寄存器 | 读写 | 复位值 | 位定义 |
|---|---|---|---|---|
| 0x0 | CTRL | RW | 0x0000_0000 | bit0=VEN（视频使能），bit1=VIE，bit2=HIE，bit3=VBSIE，bit5=VBSWE，bit7:9=CD（色深 0=8bpp 1=16bpp 2=24bpp），bit12=HSL，bit13=VSL，bit14=CSL，bit15=BL（极性/消隐电平，1=负有效）；其余保留读 0 |
| 0x4 | STAT | R/写 1 清 | 0x0000_0000 | bit0=SINT，bit1=LUINT（行 FIFO 欠载），bit4=VINT，bit5=HINT，bit6=VBSINT；bit16=AVMP（活动显存页），其余保留读 0 |
| 0x8 | HTIM | RW | 0 | bit[31:24]=TSYNC（行同步宽度-1），bit[23:16]=TGDEL（同步后沿-1），bit[15:0]=TGATE（有效行宽-1） |
| 0xC | VTIM | RW | 0 | 同构：场同步宽度/后沿/有效行数（-1 编码） |
| 0x10 | HVLEN | RW | 0 | bit[27:16]=THLEN（行总长-1），bit[11:0]=TVLEN（场总长-1） |
| 0x14 | VBARA | RW | 0 | 显存 bank A 起始地址（字节地址，按色深对齐） |
| 0x18 | VBARB | RW | 0 | 显存 bank B 起始地址 |

未定义地址（0x1C-0x3C）读回 0x0000_0000，写忽略。

| 编号 | 要求 | 关键度 |
|---|---|---|
| VGA-DRQ-FUN-001 | 寄存器读写经处理器侧总线单周期完成（零等待）；上表地址、位定义、读写属性与复位值逐项实现。 | 关键 |
| VGA-DRQ-FUN-002 | 视频使能：VEN=0 期间无像素输出（消隐电平、同步按极性位静止），取数接口无请求；VEN=1 后从下一场边界起按配置扫描。VEN=1 期间改 HTIM/VTIM/HVLEN 的生效点为下一场边界（场间原子切换）。 | 关键 |
| VGA-DRQ-FUN-003 | 行时序：每行按 [同步 TSYNC+1 | 后沿 TGDEL+1 | 有效 TGATE+1 | 前沿 = THLEN+1 − 前三段] 展开，同步脉冲极性按 HSL；行计数器在有效区外保持消隐。 | 关键 |
| VGA-DRQ-FUN-004 | 场时序：每场按 VTIM/HVLEN 同构展开，场同步极性按 VSL；行/场计数从 0 起，场尾回卷与行尾回卷原子。 | 关键 |
| VGA-DRQ-FUN-005 | 像素通路：有效区内按色深从显存取数输出 RGB（8bpp=灰度扩展 R=G=B；16bpp=RGB565；24bpp=RGB888）；色深变更在下一场生效。 | 关键 |
| VGA-DRQ-FUN-006 | 显存取数接口：只读、按地址递增突发（长度可编程，VBL=1/2/4/8），行/场回扫期预取使行有效区内不断流；bank 起始地址在每场开始装载。 | 关键 |
| VGA-DRQ-FUN-007 | 双 bank：VBSWE=1 时写 VBARB 后在下一场边界切换活动 bank（A↔B），切换完成置 VBSINT，STAT.AVMP 反映活动页；VBSWE=0 时仅 A 有效。 | 关键 |
| VGA-DRQ-FUN-008 | 中断：VINT（场回扫起始）、HINT（行回扫起始）、VBSINT（bank 切换完成）、LUINT（行 FIFO 欠载：有效区内取数接口未就绪）各自置 STAT 位；CTRL 对应使能位开放时 irq 有效（电平）；STAT 对应位写 1 清除。 | 重要 |
| VGA-DRQ-FUN-009 | 复位行为：复位释放后确定静止态——VEN=0 默认、所有计数器清零、中断挂起清零、寄存器恢复默认值。 | 关键 |

## 4. 性能要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| VGA-DRQ-PERF-001 | 系统时钟 100 MHz，单时钟域；像素节拍以内部使能脉冲产生（pix_ce，每像素一拍）。 | 关键 |
| VGA-DRQ-PERF-002 | 640×480@60 档：pix_ce 为 100 MHz 的 4 分频（每 4 拍 1 像素）时行/场时序计数与 VESA 640×480@60 规范一致（H=96/48/640/16，行总 800；V=2/29/480/13，场总 525）。 | 关键 |
| VGA-DRQ-PERF-003 | 资源预算：FF ≤ 6000，LUT ≤ 10000，BRAM ≤ 16（行缓冲），不用 DSP。 | 重要 |

## 9. 测试要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| VGA-DRQ-TST-001 | 自检 TB 以寄存器任务模拟处理器侧，显存侧挂同步存储模型（预载已知像素图案），视频侧以 pix_ce 对齐采样并按计数单位（像素/行/场）核对时序与数据；期望值由 TB 内建参考产生，不得取自 DUT。失败 `$fatal` 打印场景号、期望与实际；全过打印 PASS。 | 关键 |
| VGA-DRQ-TST-002 | 必测场景（按 VESA 640×480@60 编程，除非另注）：(a) 复位默认值与静止输出；(b) 行时序逐段宽度（同步 96/后沿 48/有效 640/前沿 16，总 800）与同步极性两档；(c) 场时序逐段（2/29/480/13，总 525）；(d) 三种色深各一行有效区像素流比对（8bpp 灰度/16bpp RGB565/24bpp RGB888）；(e) 显存地址映射（VBARA 起址、行跨距=有效宽×色深字节、跨行取数序列正确）；(f) 双 bank 切换（VBSWE 写后下一场边界生效、AVMP 翻转、VBSINT 置位）；(g) 中断链路（VINT/HINT 使能门控、STAT 写 1 清除）；(h) 欠载注入（fb_rvalid 延迟）→LUINT+消隐+恢复；(i) 非标准时序编程（改 TGATE/THLEN 短行）验证参数化通用性；(j) VEN 门控（0→无输出无取数请求）。 | 关键 |
| VGA-DRQ-TST-003 | 每条需求规定验证方法并双向可追溯。 | 关键 |
