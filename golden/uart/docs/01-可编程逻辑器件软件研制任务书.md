## 1 范围

### 1.1 标识

项目标识为 GOLDEN-UART；PLDS 名称为 UART 收发器，通用核顶层标识 `uart_top`，预留板级包装顶层 `uart_board_top`；目标器件为 AMD Xilinx Virtex-7 XC7VX690T，选定候选 Vivado part `xc7vx690tffg1761-2`；文档版本为 v2.3 candidate，无发布号、批准基线或产品基线。该 part 须先由目标 Connector 执行 `get_parts -quiet xc7vx690t*` 返回精确匹配；已知 worker-66 的 Vivado 2021.1 不包含它。

### 1.2 系统概述

本候选为 Synthia FPGA 工程流程参考项目，以 9600 bit/s、8N1、全双工 UART 为基线，并将 115200 bit/s 列为扩展回归组合。外部同步逻辑按字节提交发送数据并捕获接收结果，PLDS 在一对异步串行线 `txd/rxd` 上转换帧格式。`uart_top` 保持与板卡无关，后续由 `uart_board_top` 对接板载 USB-UART。项目已选用“项目定义的非安全关键/低关键性 + 中等保证严谨度”，该描述不冒充 GJB 9432 的通用等级。

### 1.3 文档概述

本文规定开发目的、任务、指标、接口、约束、质量和交付要求，是 UART-DOC-002 PLDSRS 的候选上游。任务要求使用 `UART-DRQ-*` 唯一标识，完整追踪见 UART-DOC-007。

## 4 任务要求

### 4.1 功能要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| UART-DRQ-FUN-001 | 实现相互独立、可同时工作的全双工 UART 收发通道。 | 关键 |
| UART-DRQ-FUN-002 | 发送 1 位低起始、8 位 LSB 先发数据、1 位高停止、无校验的 8N1 帧。 | 关键 |
| UART-DRQ-FUN-003 | 接收通道以中点采样恢复 8N1 帧并输出有效字节完成指示。 | 关键 |
| UART-DRQ-FUN-004 | 停止位为低时报告帧错、丢弃错误字节并能在线路恢复后接收后续帧。 | 关键 |
| UART-DRQ-FUN-005 | 线路空闲和复位后 `txd` 为高电平。 | 重要 |

### 4.2 性能要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| UART-DRQ-PERF-001 | 标称 9600 bit/s；本机误差不大于 ±0.5%，对端偏差 ±2% 时正确接收。 | 关键 |
| UART-DRQ-PERF-002 | 系统时钟按 100 MHz 设计，时钟与波特率应参数化。 | 重要 |
| UART-DRQ-PERF-003 | 连续吞吐率不低于 960 byte/s（10 bit/帧）。 | 重要 |
| UART-DRQ-PERF-004 | 在不改变帧语义的情况下，以 115200 bit/s、8N1 执行扩展参数回归，重新计算分频误差、采样余量和吞吐。 | 重要 |

建立/保持时间、外部 I/O 时序和板级余量未提供，列入 UART-OQ-001。

### 4.3 算法要求

接收应从同步后的起始下降沿计时，在半位处确认起始位，其后每隔一个整位时间采样数据与停止位；发送分频取 `CLK_FREQ / BAUD_RATE` 的整数向下取整值。算法细化及误差预算见 UART-DOC-003。

## 5 接口关系

```mermaid
flowchart LR
  HOST[同步外部逻辑] <-->|tx_data/tx_start/tx_busy/tx_done<br/>rx_data/rx_done/frame_err| DUT[uart_top]
  DUT -->|txd 9600 8N1| LINE[异步串行线路]
  LINE -->|rxd 9600 8N1| DUT
```

| 编号 | 接口要求 |
|---|---|
| UART-DRQ-IF-001 | 发送接口含 `tx_data[7:0]`、`tx_start`、`tx_busy`、`tx_done`；忙时忽略新请求。 |
| UART-DRQ-IF-002 | 接收接口含 `rx_data[7:0]`、单拍 `rx_done` 和单拍 `frame_err`。 |
| UART-DRQ-IF-003 | 串行接口为一位 `txd` 输出和一位 `rxd` 输入；LOC/IOSTANDARD 待板级事实。 |
| UART-DRQ-IF-004 | 使用单一 `clk` 和同步高有效 `rst`。 |

## 6 关键性要求

### 6.1 可靠性

| 编号 | 要求 |
|---|---|
| UART-DRQ-REL-001 | 异步 `rxd` 进入功能逻辑前经过至少两级带 `ASYNC_REG` 的同步寄存器。 |
| UART-DRQ-REL-002 | 复位后状态确定；非法 FSM 状态下一拍恢复空闲。 |
| UART-DRQ-REL-003 | 帧错、毛刺和持续低电平不得导致死锁或伪造有效字节。 |

### 6.2 安全性

本项目暂定义为非安全关键/低关键性，但采用中等保证严谨度：必须保留 RX 两级同步与 CDC 独立评审、需求—设计—代码—测试双向追踪、覆盖分母/目标审定、独立验证、目标 part 上的综合/实现/DRC/STA，以及板级资料完整后的实物回归。真实系统危害分析仍待系统/安全责任人审查；若危害结论与暂定义冲突，必须升级保证策略。

### 6.3 软件可编程要求

外部逻辑在发送空闲时以 `tx_start` 提交 `tx_data`，并在 `tx_done`、`rx_done`、`frame_err` 单拍有效时捕获结果；无地址映射寄存器或处理器总线接口。

### 6.4 保密性

本节无内容。项目未提供运行保密环境、类型或等级；该空缺不是“不适用”批准，数据分类须由授权角色决定。

### 6.5 其他要求

| 编号 | 要求 |
|---|---|
| UART-DRQ-TST-001 | 提供自检 TB，覆盖复位、格式、环回、帧错、容差等，失败 `$fatal`，全部成功打印 PASS。 |
| UART-DRQ-TST-002 | 支持 `txd` 直连 `rxd` 的环回验证。 |
| UART-DRQ-TST-003 | 每条 PLDSRS 需求规定验证方法并双向追踪。 |

## 7 设计约束

| 编号 | 约束 |
|---|---|
| UART-DRQ-DEV-002 | 纯 RTL，不使用厂商 IP、BRAM、DSP、MMCM/PLL。 |
| UART-DRQ-ENV-002 | RTL 使用 Verilog-2001 可综合子集，TB 可用 SystemVerilog；复位显式、无锁存、FSM 有 default 恢复。 |
| UART-DRQ-RES-001 | 候选预算：FF≤200、LUT≤300、BRAM/DSP=0；100 MHz 时序无负裕量。 |

管脚、Bank 电压、IOSTANDARD、配置电压和 I/O delay 未决；正式 `uart.xdc` 不降低 NSTD-1/UCIO-1，探索 XDC 不得进入门禁或发布。

## 9 质量保证

### 9.1 标准

PLDS 专用文档按 GJB 9764-2020 编制；该标准明确指定的通用文档类型按 GJB 438B-2009 对应附录编制。其他开发、测试、约束标准须由质量角色取得受控版本后确定适用性。

### 9.2 文档

本项目至少维护 UART-DOC-000～008；正式文档须审查封面、修改页、目录、正文顺序、裁剪、引用、追踪和证据一致性。

### 9.3 配置管理

源码、TB、XDC 和文档使用唯一标识、版本和 SHA-256；运行绑定冻结输入，旧证据不得冒充当前版本证据。

### 9.4 测试要求

仿真使用独立的 PLDSSTP、PLDSSTD、PLDSSTR。配置项确认通常还需要 PLDSVTP、PLDSVTD、PLDSVTR，但当前因板级输入缺失而阻塞。

本节无内容。当前无已识别分承制方；如引入第三方，应补充其配置、质量、验证和交付要求。
