## 1. 结论先行

当前候选通过了真实 Connector 上的源码读取、XSim 行为仿真、综合和探索性实现；使用正式 fail-closed XDC 的实现按预期失败且未产生 bitstream。

这些运行全部由 Core 判定为 `exploratory`：它们证明候选的技术状态和负向防护，不计入 G4～G8 门禁、正式覆盖、批准需求通过率、基线或发布。

## 3. XSim 行为仿真

XSim 运行参数为 DUT 默认 100 MHz / 9600 bit/s，仿真在 17,265,065 ns 结束。原始 simulator stdout 显示：

- CASE 01～10 全部完成，其中 CASE-10 向 TX/RX 注入保留非法状态 3'b111 并验证下一拍恢复及后续功能帧；
- 最终标记：`PASS: 10 UART requirement cases passed; tx_done=10 rx_done=13 frame_err=1`；
- 连续 TX 起始沿间隔：1,041,610 ns，小于 960 byte/s 的 1,041,666 ns 上限；
- phase=`simulate`、phase exit code=0、Vivado exit code=0；
- `worker-result.json` SHA-256：`445dc3e152240202f41aabe9a7c96204700f5b91551aedef33b74709c1cd90bd`。

该运行覆盖正常帧、边界码型、不同字节同时收发、假起始、坏停止位及恢复、±2% 端点、连续 RX、发送中复位、吞吐和保留状态故障注入。代码/功能覆盖数据库和门级仿真未包含。

## 5. 探索性实现

使用 `uart_exploratory.xdc` 的实现成功：

- 实现后资源：59 LUT / 69 FF，BRAM=0，DSP=0；
- Setup WNS=6.752 ns、TNS=0、0 failing endpoints；
- Hold WHS=0.108 ns、THS=0、0 failing endpoints；
- 报告称所有用户指定时序约束满足；
- DRC 共 3 项：CFGBVS-1、NSTD-1、UCIO-1，均为 Warning；
- 产生的 `synthia.bit` SHA-256 为 `ba4d39139e54d1565798c72a2208b927290fd710ccb6965d135fc1a41723a107`。

这份 bitstream 只证明降级诊断路径可运行。它明确是非交付、非板测、非门禁产物，不得下载到未知板卡或进入任何基线/发布清单。STA 也只覆盖当前已指定的 100 MHz 时钟，不代表顶层 I/O 时序已闭合。

## 6. 正式候选 XDC 负向验收

使用 `uart.xdc` 的实现按预期失败：

- NSTD-1：25/25 逻辑端口没有明确 IOSTANDARD，Critical Warning；
- UCIO-1：25/25 逻辑端口没有 LOC，Critical Warning；
- CFGBVS-1：缺少 CFGBVS/CONFIG_VOLTAGE，Warning；
- Vivado exit code=1，Core/Worker 状态为 failed；
- evidence 中有 synth/routed DCP、DRC、STA、资源和 worker result，但没有 `synthia.bit`。

这证明正式候选在板级事实缺失时 fail-closed。正确处置是取得权威原理图、Bank/配置电压、引脚、电平标准和接口时序预算后补全 XDC，再重新审查和回归；不是降低 DRC 严重度。
