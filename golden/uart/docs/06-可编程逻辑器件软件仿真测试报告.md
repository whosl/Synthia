## 1 范围

### 1.1 标识

本报告记录 GOLDEN-UART 通用核 `uart_top` 在历史目标 `xc7k70tfbv676-1`、9600 配置上的运行。本报告绑定运行时的 RTL/TB/XDC 精确哈希；结果状态为 historical/exploratory，未经验证负责人批准。项目当前目标已改为 XC7VX690T，候选 part 尚未确认，因此这里的综合、实现、资源和 STA 结果不得继承为 690T 证据。

### 1.2 系统概述

历史被测 PLDS 是 100 MHz、9600 bit/s、8N1 全双工 UART，含四个 RTL 模块和自检 TB。115200 扩展回归尚未执行；`uart_board_top` 及板载 USB-UART 未纳入本报告。

### 1.3 文档概述

本文记录行为仿真、源码校验、综合、STA 和 fail-closed 负向实现结果，分析追踪与覆盖缺口。它不替代原始 ToolRun、日志或授权批准。数据分类尚待授权角色确定。

## 3 测试概述

### 3.1 测试过程

初次独立外部验收发现四个接收语义错误：坏停止位仍产生 `rx_done`、更新 `rx_data`、持续低电平误触发第二帧、恢复路径不能满足验收。RTL 随后增加同步后下降沿检测并把合法/错误停止位处理分离；回归执行 Golden 自带 10 用例和独立外部 9 用例。此次文档重组不修改被测 HDL。

| 阶段 | 活动 | 结果/边界 |
|---|---|---|
| 初次测试 | 外部 UART 验收 | 4 项错误，已保留并形成 UART-ISS-009 |
| 修复 | 修改 `uart_rx.v` 和相应用例 | 候选，不等于批准 |
| 回归 | Icarus + 两套 XSim | 9600 内部 10/10、外部 9/9 historical/exploratory 通过；115200 未执行 |
| 静态/实现 | 源码校验、综合、正式 XDC 负向实现 | K70T 历史校验/综合成功；实现因缺 I/O 事实按预期阻断，无 bitstream；非 690T 证据 |

### 3.2 仿真测试环境

Vivado/XSim 2021.1 build 3247384、IP build 3246043；Icarus Verilog 本机交叉检查。Vivado 工具链 profile 为 `57fd8374073877701cda45e6a84f516e6d9aef0df4affb03482280312c352755`。

## 4 详细测试结果

### 4.1 仿真测试执行结果

#### 4.1.1 功能仿真测试结果总结

Golden 自带回归打印：`PASS: 10 UART requirement cases passed; tx_done=10 rx_done=12 frame_err=1`。独立外部验收打印：`PASS: external UART requirements passed`。Icarus 与两套真实 XSim 的最终判断一致。

| 用例 | 状态 | 实际结果摘要 |
|---|---|---|
| STC-01 | passed/exploratory | TX 8N1 格式、busy、忙期拒绝和单拍 done 正确 |
| STC-02 | passed/exploratory | A5/00/FF/3C 环回正确 |
| STC-03 | passed/exploratory | TX=C3、RX=5A 同时完成且独立 |
| STC-04 | passed/exploratory | 1/4 位毛刺无完成/帧错 |
| STC-05 | passed/exploratory | 坏停止位仅 frame_err，不更新数据/不伪完成；持续低不重触发，69 恢复正确 |
| STC-06 | passed/exploratory | +2%/-2% 端点均正确 |
| STC-07 | passed/exploratory | 12/E7 连续 RX 无丢帧 |
| STC-08 | passed/exploratory | 发送中复位安全，释放后 D2 正常 |
| STC-09 | passed/exploratory | 起始间隔 1,041,610 ns，小于 1,041,666 ns |
| STC-10 | passed/exploratory | TX/RX 非法 `3'b111` 下一拍恢复，4B 后续环回成功 |

##### 4.1.1.1 遇到的问题：UART-STC-05

初次外部验收发现 UART-ISS-009：错误停止位仍被当作有效完成、覆盖数据，持续低又触发第二帧。根因为 STOP 状态没有把有效/错误完成语义分离，IDLE 采用电平而非新下降沿启动。修改为合法停止位才更新数据/产生 `rx_done`，错误停止位只产生 `frame_err`，并以 `rxd_sync_d/rxd_sync` 检测新下降沿；回退点为全量 10+9 用例回归。回归未复现原四项错误。

##### 4.1.1.2 与测试用例/过程的偏差

无已知动态用例过程偏差。结果为 exploratory 而非获批正式执行，这是运行分类差异，不应隐藏为“正式通过”。

#### 4.1.2 门级仿真测试结果总结

#### 4.1.3 时序仿真测试结果总结

本节无执行结果。没有完成 SDF 时序仿真；STA 结果见 §4.1.4。

#### 4.1.4 静态时序分析结果总结

## 5 评估和建议

### 5.1 PLDS 问题分析

UART-ISS-009 的根因和修复已由全量动态回归旁证。其余主要缺口不是动态失败：CDC 工具报告、覆盖率、门级/SDF、完整板级约束和确认测试尚未完成。

### 5.2 全面评估

历史 RTL/9600 输入满足已执行的功能、异常、±2% 容差和吞吐用例；K70T 历史综合为 63 LUT/70 FF、BRAM/DSP=0，内部 100 MHz STA 有正裕量。当前 XC7VX690T 目标仍缺精确 part 确认、115200 扩展回归、批准快照、独立审查、中等保证覆盖、批准 CDC 报告、I/O 时序、电气、板卡、强度/安全/功耗分析和实物测试。不能据此声明 690T 合格、GJB 符合、门审通过、基线建立、板级可用或可交付。

### 5.3 测试环境影响

仿真环境把串行边沿建模为理想数字事件，不能覆盖亚稳态概率、抖动分布、线缆/收发器电气、温压、辐照、配置上电和板级集成。Icarus 与 XSim 交叉一致降低了单工具行为差异风险，但不消除以上环境差异。

### 5.4 测试改进建议

1. 由系统/安全角色复核低关键性分类，批准中等保证的验证独立性、覆盖模型和门级/SDF 适用性；
2. 先通过 Connector/Vivado 查询确认精确 XC7VX690T part，再对冻结快照执行 9600/115200 正式 CDC/RDC、Lint、覆盖和 XSim 回归；
3. 取得板卡、引脚、电平、时序预算和仪器后编制 PLDSVTP/PLDSVTD 并执行确认测试；
4. 所有结果继续绑定精确哈希、原始日志和不可变审批记录。
