## 4. 评审检查单

| 编号 | 检查项 | 依据 | 结果 |
|---|---|---|---|
| C-01 | 顶层端口表与 RTL 声明逐项一致（方向、位宽、极性）：clk、rst、tx_start、tx_data[7:0]、txd、tx_busy、tx_done、rxd、rx_data[7:0]、rx_done、frame_err | UART-SRS-IF-001 | 通过 |
| C-02 | 握手语义：tx_start 仅在 IDLE 采样（忙期忽略）；tx_done/rx_done/frame_err 块首默认拉低、仅完成当拍置位（单拍脉冲） | UART-SRS-IF-002、FUN-003 | 通过 |
| C-03 | 串行位序 LSB 先发/先收，帧格式 8N1（TX：data_reg[bit_idx]；RX：data_reg[bit_idx]←rxd_sync） | UART-SRS-IF-003、FUN-002 | 通过 |
| C-04 | rxd 经 rxd_sync 寄存器同步后使用（复位值=1，线路空闲电平）；无其他异步输入直用 | UART-SRS-CKR-003 | 通过（单级同步风险见 UART-ISS-005） |
| C-05 | 发送/接收状态机均含 default 分支，下一拍回 IDLE | UART-SRS-REL-001 | 通过 |
| C-06 | 参数化 CLK_FREQ/BAUD_RATE 生效；CLKS_PER_BIT 由参数表达式 `(CLK_FREQ + BAUD_RATE/2)/BAUD_RATE` 自动生成，无手写魔法数 | UART-SRS-TST-002、TIM-001 | 通过 |
| C-07 | 同步高有效复位覆盖全部状态/计数/输出寄存器，复位值与 SRS CKR-002 逐项一致（txd=1、rxd_sync=1 等） | UART-SRS-CKR-002 | 通过 |
| C-08 | 无推断锁存器（全部时序逻辑在单 always 块内带复位分支） | 编码规范 | 通过 |
| C-09 | 单时钟域、无门控时钟、无内部生成时钟（baud_tick 为使能脉冲非时钟） | UART-SRS-CKR-001 | 通过 |
| C-10 | 分频计算与误差分析复核：CLKS_PER_BIT=10417，实际 9599.69 bit/s，误差 −0.003% ≤ ±0.5% | UART-SRS-TIM-001/002 | 通过 |
| C-11 | 容差分析闭合：±2% 偏差下最坏采样点（9.5 位）累积 0.19 位 < 0.5 位余量 | UART-SRS-TIM-003 | 通过 |
| C-12 | XDC 含 create_clock（10.000 ns）；NSTD-1/UCIO-1 降级豁免显式注明 smoke 用途及板级移植时删除要求 | UART-DRQ-ENV-003 | 通过 |
| C-13 | 追踪矩阵无孤立项；需求—设计—RTL—用例同源 | TRACEABILITY-DATA-MODEL §5 | 通过 |
| C-14 | 接收异常语义：frame_err=~rxd_sync（停止位中点）与 rx_done 同拍独立；假起始位（半位中点采样为高）回 IDLE；STOP 完成当拍无条件回 IDLE | UART-SRS-FUN-006/007、REL-002 | 通过 |
| C-15 | TB 自检：失败 $fatal 并打印实测值、通过打印 PASS、含超时看门狗；环回连接 .rxd(txd) | UART-DRQ-TST-001 | 通过 |

## 5. 发现问题与处置

| 编号 | 问题 | 严重度 | 处置 | 状态 |
|---|---|---|---|---|
| UART-ISS-001 | 结构图初版未区分"baud_gen 仅服务发送通道、接收通道内部自定时"，易被误读为收发共享节拍源 | 轻 | v1.0 结构图（UART-DOC-003 §3.2）与 §5 已明确两通道位时基准独立及各自对齐方式 | 关闭 |
| UART-ISS-002 | rx_done/frame_err/tx_done 单拍脉冲存在外部漏采风险 | 轻 | 作为设计约束写入 UART-DOC-003 §4.1 接口契约与 §7 风险表（UART-RISK-002）；TB 已按当拍捕获验证 | 关闭 |
| UART-ISS-003 | 板级引脚/电平未决，XDC 仅有豁免声明 | 轻 | 登记开放问题 UART-OQ-001；板级确定后删除豁免、补全 PACKAGE_PIN/IOSTANDARD 并重走 G4 门禁 | 接受（挂起） |
| UART-ISS-004 | TB 为冒烟级覆盖：帧错误注入、毛刺注入、非法状态强制、±2% 波特率容差激励未纳入；对应需求（FUN-004/006/007、REL-001/002、TIM-003）以审查/分析闭环 | 轻 | 接受：冒烟级黄金模板范围内审查/分析证据充分（C-05/C-14、A-02）；扩展 TB 用例列入后续改进项，纳入正式确认测试（G7）前必须补齐仿真证据 | 接受（挂起） |
| UART-ISS-005 | rxd 为单级寄存器同步，非常见两级同步，存在残余亚稳态风险 | 轻 | 评估接受：9600 bit/s 低速率、中点采样、同步寄存器复位取空闲电平，失效概率极低（UART-RISK-003）；若提高波特率或可靠性等级，应改两级同步并重审 | 接受（挂起） |

评审无严重/中等问题；全部问题处置完毕或经批准挂起。

## 6. 评审结论

1. 设计满足 UART-DOC-002 全部需求，需求分配无缺口（UART-DOC-006 §2/§3 覆盖率 100%）；
2. 详细设计达到可无歧义编码的深度，关键异常语义闭合（frame_err/rx_done 独立性、假起始位剔除、default 自恢复）；
3. 代码审查通过，候选 RTL/TB/XDC 与批准设计一致；
4. 板级确认测试（G8）因无板卡裁剪，以仿真证据闭环，裁剪依据：UART-OQ-001，风险已接受；
5. **结论：通过。** 同意建立设计输入基线 B1，并同意在仿真证据齐备后提交 G4 建立 RTL 基线 B2。
