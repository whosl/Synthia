## 1. 范围

### 1.1 标识

- 项目标识：GOLDEN-UART（Synthia 黄金模板对照项目）
- 产品名称：UART 收发器可编程逻辑器件软件（PLDS）
- 目标器件：Xilinx Kintex-7，型号 xc7k70tfbv676-1
- 适用阶段：G0～G4（需求、设计、RTL 基线），对应 GOLDEN-FLOW-SPEC §5.1～§5.5

### 1.2 系统概述

本项目实现一个通用异步收发器（UART）PLDS，工作于 9600 bit/s、8 位数据、无校验、1 位停止位（8N1）模式。PLDS 对外提供并行发送/接收接口和一对串行引脚（txd/rxd），由外部系统逻辑按字节写入待发数据、按字节读取接收数据。PLDS 内部包含波特率发生器和发送、接收两个独立状态机，支持全双工同时收发。

```mermaid
flowchart LR
    HOST["外部系统逻辑\n(并行字节接口)"] <-->|"tx_data/tx_start/tx_busy/tx_done\nrx_data/rx_done/frame_err"| DUT["UART 收发器 PLDS\n(uart_top)"]
    DUT -->|"txd"| LINE["异步串行线路\n9600 8N1"]
    LINE -->|"rxd"| DUT
```

## 3. 功能要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| UART-DRQ-FUN-001 | PLDS 应实现全双工 UART 收发功能，发送通道与接收通道相互独立、可同时工作。 | 关键 |
| UART-DRQ-FUN-002 | 发送通道应将并行字节按 8N1 帧格式串行输出：1 位起始位（低电平）、8 位数据位（LSB 先发）、1 位停止位（高电平），无校验位。 | 关键 |
| UART-DRQ-FUN-003 | 接收通道应采用中点采样方式从串行输入恢复 8N1 帧，输出并行字节及接收完成指示。 | 关键 |
| UART-DRQ-FUN-004 | 接收通道应检测帧错误（停止位采样为低电平），并给出错误指示；检测到帧错误后应能自动恢复，继续接收后续帧。 | 重要 |
| UART-DRQ-FUN-005 | 串行线路空闲电平应为高电平；复位后 txd 输出应处于空闲高电平。 | 重要 |

## 4. 性能要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| UART-DRQ-PERF-001 | 标称波特率 9600 bit/s；PLDS 自身波特率相对误差应不大于 ±0.5%；应能在对端波特率偏差 ±2% 的条件下正确接收。 | 关键 |
| UART-DRQ-PERF-002 | 系统工作时钟按 100 MHz 设计；波特率发生参数应可通过参数化方式适配其他时钟频率。 | 重要 |
| UART-DRQ-PERF-003 | 连续收发吞吐率应不低于 960 字节/s（每帧 10 位，背靠背发送无间隔）。 | 重要 |

## 5. 接口要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| UART-DRQ-IF-001 | 发送并行接口：8 位数据输入、发送启动输入、发送忙输出、发送完成输出；忙期间不应接受新的发送请求。 | 关键 |
| UART-DRQ-IF-002 | 接收并行接口：8 位数据输出、接收完成输出（单时钟周期脉冲）、帧错误输出（单时钟周期脉冲）。 | 关键 |
| UART-DRQ-IF-003 | 串行接口：txd 输出、rxd 输入，各 1 位；引脚分配与电平标准由板级约束（XDC）定义，属未决板级项。 | 关键 |
| UART-DRQ-IF-004 | 时钟与复位：单一时钟输入，单一复位输入；复位极性、施加与释放方式由结构设计统一规定。 | 关键 |

## 6. 器件要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| UART-DRQ-DEV-001 | 目标器件为 xc7k70tfbv676-1（Kintex-7，速度等级 -1）；设计不得使用超出该器件资源的结构。 | 关键 |
| UART-DRQ-DEV-002 | 设计应纯逻辑实现，不依赖 Block RAM、DSP 等硬核资源，不使用厂商 IP 核。 | 重要 |

## 7. 环境与工具要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| UART-DRQ-ENV-001 | 开发、综合与实现工具链为 Vivado 2021.1；仿真工具为 XSim。 | 关键 |
| UART-DRQ-ENV-002 | RTL 采用 Verilog-2001 可综合子集；测试平台可采用 SystemVerilog；代码须符合项目编码规范（复位方式显式写明、禁止推断锁存器、状态机含 default 自恢复分支）。 | 关键 |
| UART-DRQ-ENV-003 | 正式约束文件应包含有依据的时钟、引脚、I/O 电平及适用的 I/O 时序约束；缺少板级事实时正式实现必须 fail-closed。探索性运行可使用独立 XDC 显式降级 NSTD-1/UCIO-1，但该结果不得计入门禁、基线或发布。 | 关键 |

## 8. 安全可靠性要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| UART-DRQ-REL-001 | 异步串行输入 rxd 进入功能逻辑前应经过至少两级、带 ASYNC_REG 属性的同步寄存器；功能逻辑只能使用末级同步输出。该结构仅降低亚稳态传播概率，不表示消除风险。 | 关键 |
| UART-DRQ-REL-002 | 复位释放后全部内部状态应处于确定的初始值；任何非法状态应具备自恢复能力（默认回到空闲）。 | 关键 |
| UART-DRQ-REL-003 | 帧错误、线路毛刺等异常不应导致状态机死锁。 | 重要 |

## 9. 测试要求

| 编号 | 要求 | 关键度 |
|---|---|---|
| UART-DRQ-TST-001 | 应提供自检仿真测试平台，覆盖复位、发送帧格式、环回接收、帧错误和波特率容差场景；测试失败须以 `$fatal` 报错，全部通过须打印 PASS。 | 关键 |
| UART-DRQ-TST-002 | 发送通道与接收通道应支持环回（txd 直连 rxd）验证。 | 重要 |
| UART-DRQ-TST-003 | 每条 PLDS 需求应规定验证方法（审查/分析/静态检查/仿真/测试），并在追踪矩阵中双向可追溯。 | 关键 |
